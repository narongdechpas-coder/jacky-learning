### 📖 เนื้อหาหลัก

#### 1\. ข้อมูล (Data) คืออะไร

ข้อมูล คือ "ข้อเท็จจริง" ที่เราเก็บไว้ เช่น ชื่อลูกค้า, ยอดขาย, วันที่ซื้อ, จังหวัด ฯลฯ

เมื่อเอามาเรียงเป็นตาราง:

-   **1 แถว = 1 เรื่อง** (1 transaction, 1 ลูกค้า, 1 วัน)
-   **1 คอลัมน์ = 1 หัวข้อ** (วันที่, สาขา, ยอดขาย)

ตัวอย่างตารางยอดขายร้านกาแฟ *(ใช้ตลอด Phase นี้)*:

| วันที่ | สาขา | สินค้า | จำนวน | ยอดขาย (บาท) |
| --- | --- | --- | --- | --- |
| 2026-01-05 | สาขา A | กาแฟ | 3 | 105 |
| 2026-01-05 | สาขา B | ชานม | 5 | 175 |
| 2026-01-06 | สาขา A | ชานม | 2 | 70 |
| 2026-01-06 | สาขา C | กาแฟ | 4 | 140 |

> 💡 พิมพ์ตารางนี้ลง Google Sheets ใหม่ตอนนี้เลย — ใช้เป็น "สนามทดสอบ" ตลอด Phase

#### 2\. Data Types หลักที่ควรรู้

![Data Types ทั้ง 4 ประเภท](/courses/data-analysis-viz/images/phase1/phase1-data-types.webp)

| ประเภท (Data Type) | ตัวอย่าง | ใช้ทำอะไร | จุดที่มือใหม่พลาดบ่อย |
| --- | --- | --- | --- |
| **Text (ข้อความ)** | "สาขา A", "ชานมไข่มุก" | แสดงชื่อ/รายละเอียด นำมาคำนวณไม่ได้ | พิมพ์ตัวเลขแต่ระบบมองเป็น Text เลยบวกไม่ได้ |
| **Number (ตัวเลข)** | 105, 3.5, -20 | บวก ลบ คูณ หาร เฉลี่ย | พิมพ์ "1,000" หรือมีช่องว่างแฝง ทำให้กลายเป็น Text |
| **Date (วันที่/เวลา)** | 2026-01-05 | เรียงตามเวลา, หาแนวโน้มรายเดือน/ปี | พิมพ์วันที่เป็น Text เช่น "5 ม.ค. 69" ทำให้เรียงผิด |
| **Categorical (หมวดหมู่)** | "สาขา A", "VIP", "ทั่วไป" | จัดกลุ่ม, นับจำนวน, ทำ Pivot Table | สะกดไม่เหมือนกัน เช่น "สาขาA" กับ "สาขา A" ระบบมองเป็นคนละกลุ่ม |

> 💡 **ทริคดูด้วยตา**: ตัวเลขชิดขอบ **ขวา** = Number จริง ✅ / ชิดขอบ **ซ้าย** = Text (บวกไม่ได้) ⚠️

![ตัวเลขชิดซ้าย vs ชิดขวา — ต่างกันอย่างไร](/courses/data-analysis-viz/images/phase1/phase1-number-alignment.webp)

#### 3\. หลักการจัดข้อมูลให้ "พร้อมใช้งาน" (Tidy Data)

กฎ 5 ข้อที่ต้องจำ:

1.  **1 แถว = 1 เรื่อง, 1 คอลัมน์ = 1 หัวข้อ** — ห้ามมีเซลรวม (Merge Cell) เด็ดขาด
2.  **แถวแรกเป็นหัวข้อ (Header) เท่านั้น** — ตั้งชื่อสั้น ชัดเจน ไม่เว้นแถวว่างคั่น
3.  **1 คอลัมน์ = 1 Data Type เดียว** — อย่าผสม Text กับ Number ในคอลัมน์เดียวกัน
4.  **สะกดหมวดหมู่ให้เหมือนกันทุกแถว** — "สาขา A" ต้องไม่ใช่ "สาขาA" หรือ "Sales A"
5.  **วันที่ใช้ format เดียวกันทั้งคอลัมน์** — แนะนำ `YYYY-MM-DD` เช่น `2026-01-05`

**ตัวอย่าง: ผิด vs ถูก**

| ❌ ตารางที่จัดผิด | ✅ ตารางที่จัดถูก |
| --- | --- |
| มี Merge Cell หัวตาราง | ทุกเซลแยกกันชัดเจน |
| คอลัมน์ "ยอดขาย" มีทั้ง 105 และ "ไม่มีข้อมูล" | แยกเป็น 2 คอลัมน์: ยอดขาย (Number) + หมายเหตุ (Text) |
| เว้นแถวว่างระหว่าง section | ข้อมูลต่อเนื่องตั้งแต่แถว 2 ลงไป |
| วันที่เขียนทั้ง "5/1/26" และ "2026-01-05" | วันที่ใช้ "YYYY-MM-DD" ทั้งคอลัมน์ |
| สาขา A, สาขาA, Sales A ปนกัน | "สาขา A" ทุกแถว |

![ตาราง Tidy Data ที่ถูก vs ผิด](/courses/data-analysis-viz/images/phase1/phase1-tidy-vs-messy.webp)

### ⚡ Quick Win (ทดสอบได้ใน 5 นาที)

ทดสอบความแตกต่างระหว่าง Number กับ Text ด้วยตัวเอง:

1.  เปิด Google Sheets ใหม่ (sheets.new)
2.  เซล **A1** พิมพ์ `1000` → กด Enter
3.  เซล **A2** พิมพ์ `1,000` (มีคอมมา) → กด Enter
4.  เซล **A3** พิมพ์ `=A1+A2` → กด Enter

**คุณควรเห็น:**

-   A1: ตัวเลขชิด**ขวา** (Number จริง ✅)
-   A2: ตัวเลขชิด**ซ้าย** (Text ⚠️)
-   A3: ได้ค่า `1000` ไม่ใช่ `2000` เพราะ A2 เป็น Text บวกไม่ได้

✅ ถ้าเห็นแบบนี้ → เข้าใจปัญหา "ตัวเลขที่จริงเป็น Text" แล้ว นี่คือสาเหตุ 90% ของ error ในออฟฟิศ

### 💬 Prompt สำเร็จรูป

ใช้ใน **Claude Chat** เพื่อช่วยตรวจสอบ Data Type ของชุดข้อมูล:

```
[Context] ฉันมีตารางข้อมูลยอดขายใน Google Sheets มีคอลัมน์: วันที่, สาขา, สินค้า, จำนวน, ยอดขาย
[Task] ช่วยตรวจสอบว่าแต่ละคอลัมน์ควรเป็น Data Type อะไร (Text/Number/Date/Categorical)
[Spec] ฉันจะ copy ข้อมูลตัวอย่าง 5 แถวแรกมาให้ดู
[Constraint] อธิบายแบบเข้าใจง่าย พร้อมบอกว่าคอลัมน์ไหนมีโอกาสพิมพ์ผิด format บ่อย
```

แล้ว copy ข้อมูล 5 แถวจาก Sheet วางต่อท้าย prompt ได้เลย

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| โครงสร้างตาราง | 1 แถว = 1 รายการ, แถวแรก = header เท่านั้น, ไม่มี Merge Cell | มีแถว/คอลัมน์ว่างคั่น หรือมี Merge Cell |
| คอลัมน์ตัวเลข | "จำนวนเงิน" ชิดขวาทุกเซล, =SUM(D2:D11) ได้ค่าถูกต้อง | มีตัวเลขชิดซ้าย หรือ SUM แล้วได้ 0 หรือ error |
| คอลัมน์หมวดหมู่ | กด Filter ที่คอลัมน์ "ประเภท" แล้วเห็นค่าไม่เกิน 4-5 ตัวเลือก (เช่น อาหาร, เดินทาง, ของใช้) | เจอหมวดหมู่คล้ายๆ กันหลาย version ("อาหาร", "อาหารการกิน", "ก๋วยเตี๋ยว") |
| คอลัมน์วันที่ | format เดียวกันทั้งคอลัมน์ (YYYY-MM-DD), เรียงลำดับได้ถูก | บางแถวเป็น Text บางแถวเป็น Date หรือ format ต่างกัน |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| `=SUM()` ได้ค่า 0 ทั้งที่มีตัวเลข | ตัวเลขถูกพิมพ์เป็น Text (ชิดซ้าย) | เลือกคอลัมน์ → Format > Number > Number หรือใช้ `=VALUE(A1)` แปลงค่า |
| เรียงวันที่แล้วลำดับผิด | วันที่บางแถวพิมพ์เป็น Text เช่น "5 ม.ค." | พิมพ์วันที่เป็น YYYY-MM-DD แล้วเลือก Format > Date ทั้งคอลัมน์ |
| Filter แล้วเจอหมวดหมู่คล้ายๆ กันเยอะมาก | สะกดไม่ตรงกัน เช่น "สาขา A" vs "สาขาA" | ใช้ Find & Replace (`Ctrl+H`) แก้ให้สะกดเหมือนกันทั้งหมด |
| ลาก SUM แล้วได้ค่าผิดทุกเซล | ลาก formula แล้ว range เลื่อนตาม | ดู section Absolute Reference ในสัปดาห์ 2 |
