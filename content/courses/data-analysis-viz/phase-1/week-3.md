## 📅 สัปดาห์ที่ 3 — Pivot Table: สรุปข้อมูลแบบมือโปร

### ⏱️ เวลาโดยประมาณ

ศึกษา 1.5 ชม. + Workshop 1.5 ชม.

### 🎯 สิ่งที่ทำได้เมื่อจบสัปดาห์นี้

-   สร้าง Pivot Table เพื่อสรุปข้อมูลแยกตามกลุ่มได้โดยไม่ต้องเขียน Formula
-   เปลี่ยน Rows/Columns/Values เพื่อดูข้อมูลจากมุมต่างๆ ได้
-   อ่านตัวเลขจาก Pivot Table และสรุป Insight ได้อย่างน้อย 2 ข้อ

### 💼 ทำไมเรื่องนี้สำคัญในงาน

สมมติมีข้อมูลยอดขาย 1,000 แถว และหัวหน้าถามว่า "สาขาไหนขายดีที่สุดเดือนที่แล้ว?" — ถ้าไม่มี Pivot Table ต้องเขียน SUMIF ทีละสาขา ทีละเดือน ใช้เวลานาน แต่ Pivot Table ทำให้ตอบได้ใน 3 คลิก

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

นึกภาพเครื่องคัดแยกลูกบอลสีต่างๆ 🎱 — เราโยนลูกบอลปนกันลงไป เครื่องจะคัดแยกเป็นกองๆ ตามสี แล้วบอกว่ากองไหนมีกี่ลูก

**Pivot Table** ทำหน้าที่แบบนั้น: รับตารางข้อมูลหลายร้อยแถว → เราบอกว่า "อยากแยกตามอะไร" และ "อยากสรุปอะไร" → ได้ตารางสรุปทันที

### 📖 เนื้อหาหลัก

![Pivot Table — จากข้อมูลดิบพันแถว สรุปได้ใน 3 คลิก](/courses/data-analysis-viz/images/phase1/phase1-pivot-concept.webp)

#### 1\. ส่วนประกอบของ Pivot Table

| ส่วน | ทำหน้าที่ | ตัวอย่าง |
| --- | --- | --- |
| **Rows** | แยกแถวตามหมวดหมู่ | สาขา, สินค้า, เดือน |
| **Columns** | แยกคอลัมน์ตามหมวดหมู่ | ปี, ประเภทลูกค้า |
| **Values** | ตัวเลขที่จะสรุป (SUM/AVERAGE/COUNT) | ยอดขาย, จำนวนบิล |
| **Filters** | กรองข้อมูลก่อนสรุป | เฉพาะปี 2026 |

#### 2\. ขั้นตอนสร้าง Pivot Table ใน Google Sheets

**ขั้นที่ 1: เตรียมข้อมูล**

1.  เปิดตารางยอดขายกาแฟ (4 แถว + header)
2.  คลิกเซลใดก็ได้ภายในตาราง

**ขั้นที่ 2: สร้าง Pivot Table**

1.  เมนู **Insert** → **Pivot table**
2.  Sheets จะถามว่าจะวางไว้ที่ไหน → เลือก **New sheet** → **Create**
3.  จะเปิด Sheet ใหม่ชื่อ "Pivot Table 1" พร้อมแผง Editor ด้านขวา

**ขั้นที่ 3: ตั้งค่าใน Editor (แผงด้านขวา)**

```
┌─────────────────────────────┐
│   Pivot table editor        │
├─────────────────────────────┤
│ Rows        [+ Add]         │  ← ลาก "สาขา" มาตรงนี้
│   สาขา ✕                   │
├─────────────────────────────┤
│ Columns     [+ Add]         │  ← (ว่างไว้ก่อน)
├─────────────────────────────┤
│ Values      [+ Add]         │  ← ลาก "ยอดขาย" มาตรงนี้
│   SUM of ยอดขาย ✕          │     แล้วตั้งค่า Summarize by: SUM
├─────────────────────────────┤
│ Filters     [+ Add]         │  ← (ว่างไว้ก่อน)
└─────────────────────────────┘
```

> 💡 **"ลาก" = คลิกค้างที่ชื่อ field แล้วลากไปปล่อยที่ช่อง** หรือคลิก **\[+ Add\]** แล้วเลือกชื่อคอลัมน์จากรายการก็ได้

**ขั้นที่ 4: ผลลัพธ์ที่ควรเห็น**

```
สาขา      | SUM of ยอดขาย
----------|---------------
สาขา A   | 245
สาขา B   | 175
สาขา C   | 140
Grand Total| 490
```

✅ ตัวเลขตรงกับที่คำนวณมือ → Pivot Table ทำงานถูกต้อง

#### 3\. เปลี่ยนมุมมอง: แยกตามสินค้าด้วย

ลากฟิลด์ **"สินค้า"** ไปที่ **Columns** ด้วย จะได้ตารางแบบ 2 มิติ:

```
สาขา      | กาแฟ | ชานม | Grand Total
----------|------|------|------------
สาขา A   | 245  |  -   | 245
สาขา B   |  -   | 175  | 175
สาขา C   | 140  |  -   | 140
Grand Total| 385 | 175  | 490
```

> 💡 ถ้าข้อมูลต้นทางเปลี่ยน ให้คลิกขวาที่ Pivot Table → **Refresh** เพื่ออัปเดตตัวเลข

### ⚡ Quick Win (ทดสอบได้ใน 5 นาที)

1.  สร้าง Pivot Table จากตารางยอดขายกาแฟ (ทำตามขั้นตอนด้านบน)
2.  ตั้งค่า: Rows = สาขา, Values = SUM of ยอดขาย

**คุณควรเห็น**: ตารางสรุปยอดขายแยกตามสาขา 3 แถว + Grand Total

1.  ลอง **เปลี่ยน Values** จาก SUM เป็น AVERAGE → สังเกตตัวเลขเปลี่ยน

**คุณควรเห็น**: ค่าเฉลี่ยต่อบิลของแต่ละสาขา แทนที่จะเป็นยอดรวม

✅ ถ้าปรับได้และตัวเลขเปลี่ยนตาม → เข้าใจ Pivot Table พื้นฐานแล้ว

### 🛠️ Workshop — Pivot Table บนข้อมูลค่าใช้จ่ายตัวเอง

เปิดไฟล์ `Workshop_Phase1_ชื่อคุณ` ต่อจากสัปดาห์ที่ 2:

1.  **ขยายข้อมูล**: เพิ่มรายการค่าใช้จ่ายให้ครอบคลุม 3-4 สัปดาห์ (หรืออย่างน้อย 25 แถว) เพิ่มคอลัมน์ **"สัปดาห์"** (สัปดาห์ที่ 1, 2, 3, 4) ลงในตาราง
    
2.  **สร้าง Pivot Table** ใน Sheet ใหม่ชื่อ `Pivot_สัปดาห์3`:
    
    -   Rows = ประเภท
    -   Values = SUM จำนวนเงิน
    -   ผลลัพธ์: เห็นว่าประเภทไหนใช้เงินมากที่สุด
3.  **เพิ่ม Columns = สัปดาห์** → เห็นว่าแต่ละประเภทใช้เงินเพิ่ม/ลดในแต่ละสัปดาห์อย่างไร
    
4.  **ทดลองเปลี่ยน Values** จาก SUM → AVERAGE → COUNT → สังเกตความหมายที่ต่างกัน
    
5.  **เขียนสรุป 2-3 ข้อ** ในเซลด้านล่าง Pivot Table เช่น:
    
    -   "ค่าอาหารสูงที่สุดในทุกสัปดาห์ คิดเป็น 45% ของค่าใช้จ่ายทั้งหมด"
    -   "ค่าเดินทางสัปดาห์ที่ 3 ลดลงครึ่งหนึ่งเพราะ WFH"

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| สร้าง Pivot Table ได้ | มีตาราง Rows = ประเภท, Values = SUM จำนวนเงิน แสดงถูกต้อง | สร้างไม่ขึ้น หรือ Values แสดง COUNT แทน SUM |
| ค่า SUM ถูกต้อง | ยอดรวมแต่ละประเภทตรงกับข้อมูลต้นทาง (สุ่มเช็ค 1-2 ประเภทด้วย SUMIF) | ตัวเลขไม่ตรง หรือแสดง 0 |
| เปลี่ยน Rows/Columns/Values ได้ | ปรับแล้วผลลัพธ์เปลี่ยนตามที่คาด | ปรับแล้วตารางไม่เปลี่ยน หรือ error |
| สรุป Insight | เขียนได้ 2 ข้อ อ้างอิงตัวเลขจาก Pivot Table จริง เช่น "อาหารใช้ X บาท" | สรุปลอยๆ ไม่มีตัวเลขอ้างอิง |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| ลาก field แล้วเลือกได้แค่ COUNT ไม่มี SUM | คอลัมน์จำนวนเงินถูกมองเป็น Text | กลับไปแก้ Data Type ของคอลัมน์นั้นในตารางต้นฉบับ (อ้างอิงสัปดาห์ 1) |
| Pivot Table ไม่อัปเดตตอนแก้ข้อมูลต้นฉบับ | ไม่ได้กด Refresh | คลิกขวาที่ Pivot Table → **Refresh** |
| ยอดรวม Grand Total เพี้ยน | มีแถวข้อมูลซ้ำ หรือเลือก range ไม่ครบ | ตรวจ range ต้นฉบับ → Data > Data cleanup > Remove duplicates |
| ไม่เห็นแผง Editor ด้านขวา | คลิกออกนอก Pivot Table ไป | คลิกที่เซลใดก็ได้ภายใน Pivot Table แผงจะกลับมา |

## 📚 Glossary (คำศัพท์น่ารู้)

| คำไทย | English Term | ความหมายสั้นๆ |
| --- | --- | --- |
| ประเภทข้อมูล | Data Type | ป้ายบอกว่าข้อมูลเป็นตัวเลข/ข้อความ/วันที่/หมวดหมู่ |
| ข้อมูลแบบตาราง | Tidy Data | รูปแบบตารางที่จัดเรียงให้พร้อมวิเคราะห์ (1 แถว = 1 เรื่อง) |
| สูตรคำนวณ | Formula | คำสั่งให้ Excel/Sheets คำนวณค่า |
| การอ้างอิงแบบล็อก | Absolute Reference | การล็อกเซลอ้างอิงด้วย `$` ไม่ให้เลื่อนตอนลากสูตร (กด F4) |
| การเรียงข้อมูล | Sort | จัดลำดับข้อมูลตามเงื่อนไข |
| การกรองข้อมูล | Filter | แสดงเฉพาะข้อมูลที่ตรงเงื่อนไข (ซ่อนแถวอื่น ไม่ลบ) |
| ตารางสรุปข้อมูล | Pivot Table | เครื่องมือสรุป/จัดกลุ่มข้อมูลอัตโนมัติโดยไม่ต้องเขียน Formula |
| ข้อมูลเชิงลึก | Insight | ข้อสรุป/มุมมองที่ได้จากการวิเคราะห์ข้อมูล |
