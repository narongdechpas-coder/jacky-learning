### 🎯 สิ่งที่ทำได้เมื่อจบสัปดาห์นี้

-   ใช้ SUM, AVERAGE, IF, COUNTIF, SUMIF คำนวณค่าจากตารางข้อมูลได้

-   กรองข้อมูล (Filter) เพื่อดูเฉพาะข้อมูลที่ต้องการได้

แทนที่จะบวกเลขทีละตัวด้วยเครื่องคิดเลข หรือกด AutoSum แบบสุ่ม — เมื่อรู้ Formula ที่ถูกต้อง คุณจะตอบคำถามอย่าง "เดือนนี้สาขา A ขายกาแฟไปเท่าไหร่?" ได้ใน 30 วินาที

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

Excel/Sheets เหมือน "ผู้ช่วยคำนวณ" ที่ทำงานเป๊ะตามคำสั่ง 🧮 ไม่เคยบ่น ไม่เคยเหนื่อย แต่ต้อง **"สั่งให้ถูก"** ไม่งั้นมันจะทำสิ่งที่เราไม่ได้ตั้งใจ (แต่ถูกตามคำสั่งจริงๆ!)

-   **Formula** = คำสั่งที่บอกว่า "ไปเอาเลขจากตรงนี้ มาบวก/เฉลี่ย/เทียบเงื่อนไข แล้วบอกผลลัพธ์"
-   **Sort** = "จัดเรียงทุกแถวให้ฉันตามลำดับที่ต้องการ"
-   **Filter** = "ซ่อนแถวที่ไม่ตรงเงื่อนไข ให้ฉันดูเฉพาะที่สนใจ"

### 📖 เนื้อหาหลัก

#### 1\. Formula พื้นฐานที่ใช้บ่อย

| Formula | ใช้ทำอะไร | ตัวอย่างจากตารางกาแฟ |
| --- | --- | --- |
| `=SUM(range)` | รวมตัวเลข | `=SUM(E2:E5)` → ยอดขายรวมทั้งหมด |
| `=AVERAGE(range)` | หาค่าเฉลี่ย | `=AVERAGE(E2:E5)` → ยอดขายเฉลี่ย/บิล |
| `=COUNT(range)` | นับจำนวนเซลที่มีตัวเลข | `=COUNT(E2:E5)` → นับจำนวนบิล |
| `=COUNTA(range)` | นับจำนวนเซลที่มีข้อมูล (รวม Text) | `=COUNTA(B2:B5)` → นับทุกแถว |
| `=IF(condition, ค่าจริง, ค่าเท็จ)` | ตรวจเงื่อนไข | `=IF(E2>100,"สูง","ปกติ")` |
| `=COUNTIF(range, condition)` | นับเฉพาะที่ตรงเงื่อนไข | `=COUNTIF(B2:B5,"สาขา A")` |
| `=SUMIF(range, condition, sum_range)` | รวมเฉพาะที่ตรงเงื่อนไข | `=SUMIF(B2:B5,"สาขา A",E2:E5)` |

> 💡 **Absolute Reference**: ถ้าอยากล็อกเซลไม่ให้เลื่อนตอนลากสูตร ใส่ `$` เช่น `$E$2` หมายความว่า "ล็อกทั้งคอลัมน์ E และแถว 2 ไว้" — ลองกด **F4** หลังพิมพ์ cell reference เพื่อใส่ `$` อัตโนมัติ

#### 2\. Sort (เรียงข้อมูล)

![เลือกทั้งตารางก่อน Sort — ห้ามเลือกแค่คอลัมน์เดียว](/courses/data-analysis-viz/images/phase1/phase1-sort-correct.webp)

**ขั้นตอน:**

1.  คลิกเซลใดก็ได้ **ภายใน** ตาราง (ไม่ใช่คลิกเฉพาะคอลัมน์เดียว)
2.  เมนู **Data** → **Sort range** → เลือก **Advanced range sorting options**
3.  ติ๊ก ☑ **Data has header row**
4.  เลือกคอลัมน์ที่จะเรียง → เลือก A→Z หรือ Z→A → **Sort**

⚠️ **ข้อผิดพลาดที่พบบ่อย**: ถ้าเลือกแค่คอลัมน์เดียวก่อน Sort ข้อมูลในคอลัมน์นั้นจะเลื่อน แต่คอลัมน์อื่นไม่ตาม — แถวจะ "หลุดคู่กัน" ข้อมูลผิดหมด ให้เลือกทั้งตารางเสมอ

#### 3\. Filter (กรองข้อมูล)

**ขั้นตอน:**

1.  คลิกเซลใดก็ได้ภายในตาราง
2.  เมนู **Data** → **Create a filter**
3.  จะเห็นปุ่มสามเหลี่ยม ▼ ที่หัวคอลัมน์ทุกคอลัมน์
4.  คลิก ▼ ที่คอลัมน์ "สาขา" → เลือกเฉพาะ "สาขา A" → **OK**

**คุณควรเห็น**: เหลือแค่แถวที่เป็นสาขา A แถวอื่นซ่อนอยู่ (ไม่ถูกลบ) เลขแถวซ้ายมือจะข้ามเลข เช่น 1, 2, 4, 7 (แถว 3, 5, 6 ถูกซ่อน)

ยกเลิก Filter: คลิก ▼ → **Select all** → **OK** หรือ Data → **Remove filter**

### ⚡ Quick Win (ทดสอบได้ใน 5 นาที)

ใช้ **ตารางยอดขายกาแฟ** ที่พิมพ์ไว้สัปดาห์ที่แล้ว (4 แถว, คอลัมน์ A-E):

1.  คลิกเซล **F1** พิมพ์ `ยอดรวม`
2.  คลิกเซล **F2** พิมพ์ `=SUM(E2:E5)` → กด Enter

**คุณควรเห็น**: `490` (105+175+70+140)

1.  คลิกเซล **F3** พิมพ์ `=SUMIF(B2:B5,"สาขา A",E2:E5)` → กด Enter

**คุณควรเห็น**: `245` (105+140 = ยอดสาขา A เท่านั้น)

✅ ถ้าเห็นตัวเลขตรงตามนี้ → Formula ทำงานถูกต้องแล้ว

### 🛠️ Workshop — เพิ่ม Formula ให้ตารางค่าใช้จ่าย

เปิดไฟล์ `Workshop_Phase1_ชื่อคุณ` ที่สร้างสัปดาห์ที่ 1 แล้วทำต่อ:

1.  สร้าง Sheet ใหม่ในไฟล์เดิม ตั้งชื่อว่า `สรุป_สัปดาห์2` — ไม่ต้องสร้างไฟล์ใหม่
2.  ใน Sheet `สรุป_สัปดาห์2` หา:
    -   **ยอดรวม** ค่าใช้จ่ายทั้งหมด (SUM)
    -   **ค่าเฉลี่ย** ต่อรายการ (AVERAGE)
    -   หมวด "อาหาร" ใช้เงินไปเท่าไหร่ (SUMIF) และกี่ครั้ง (COUNTIF)
3.  กลับไปที่ Sheet ข้อมูลหลัก → ใช้ **Sort** เรียงรายการจากมากไปน้อยตามจำนวนเงิน
4.  ใช้ **Filter** แสดงเฉพาะรายการที่มากกว่า 100 บาท → สังเกตว่าแถวซ่อนไป ไม่ถูกลบ

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| SUM/AVERAGE | ได้ค่าตัวเลขถูกต้อง ตรงกับคำนวณมือ | error หรือค่าผิด |
| SUMIF/COUNTIF | ได้ผลลัพธ์เฉพาะหมวดที่ระบุ ไม่รวมหมวดอื่น | นับ/รวมทุกหมวดปนกัน หรือได้ 0 ทั้งที่มีข้อมูล |
| Sort | ทุกคอลัมน์เลื่อนไปด้วยกัน ข้อมูลแต่ละแถวยังตรงกัน | บางคอลัมน์ไม่ขยับ ข้อมูลคู่กันผิด |
| Filter | เห็นแค่แถวที่ตรงเงื่อนไข เลขแถวซ้ายข้ามเลข | ข้อมูลหายจริง หรือ Filter ไม่ทำงาน |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| `#VALUE!` | ในช่วงที่ SUM มีเซลที่เป็น Text | ตรวจดูว่ามีเซลไหนชิดซ้าย แล้วแปลงเป็น Number |
| ลากสูตรแล้วผลลัพธ์ผิดทุกเซล | อ้างอิงเซลแบบ Relative เลื่อนตามที่ลาก | กด F4 หลัง cell reference เพื่อใส่ `$` ล็อกเซล |
| Sort แล้วข้อมูลแต่ละแถวไม่ตรงกัน | เลือกแค่บางคอลัมน์ก่อน Sort | Undo (`Ctrl+Z`) แล้วเลือกทั้งตารางก่อน Sort ใหม่ |
| COUNTIF ได้ 0 ทั้งที่มีข้อมูล | สะกดเงื่อนไขไม่ตรงกับข้อมูล | เช็คการสะกด หรือใช้ Find & Replace แก้ข้อมูลก่อน |
