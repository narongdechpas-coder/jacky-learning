## 📅 สัปดาห์ที่ 6 — AI (Claude) ช่วยวิเคราะห์ข้อมูลและหา Insight

### ⏱️ เวลาโดยประมาณ

ศึกษา 1.5 ชม. + Workshop 1 ชม.

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

ลองนึกภาพมีเพื่อนคนหนึ่งที่อ่านตัวเลขเร็วมาก จับ pattern ได้ไว 🤖 แต่เพื่อนคนนี้ "ไม่รู้บริบทธุรกิจของเรา" และ "บางทีก็มั่นใจในคำตอบที่ผิด" — Claude ก็เหมือนเพื่อนคนนี้

ถ้าเราอธิบายให้ฟังชัดๆ ว่าข้อมูลคืออะไร อยากรู้อะไร แล้ว "ตรวจทาน" คำตอบที่ได้กับตัวเลขจริงอีกที — เพื่อนคนนี้จะช่วยประหยัดเวลาได้มาก

### 📖 เนื้อหาหลัก

#### 1\. วิธีส่งข้อมูลให้ Claude วิเคราะห์

1.  Copy ข้อมูลจาก Google Sheets (เลือกช่วงเซล → `Ctrl+C`)
2.  วางในแชท Claude พร้อมอธิบาย context (ข้อมูลนี้คืออะไร มาจากไหน)
3.  ระบุคำถามที่ต้องการให้วิเคราะห์ให้ชัด (อย่าถามกว้างเกินไปแบบ "ช่วยวิเคราะห์ให้หน่อย")

> 💡 ถ้าข้อมูลมีหลายร้อยแถว ให้ตัดมาเฉพาะส่วนที่เกี่ยวข้อง หรือสรุปด้วย Pivot Table ก่อน แล้วค่อยส่งผลสรุปให้ Claude

#### 2\. การเขียน Prompt วิเคราะห์ที่ดี

ใช้โครงสร้าง Context / Task / Spec / Constraint เสมอ — ยิ่งระบุ Spec/Constraint ชัด คำตอบยิ่งตรงและตรวจสอบง่าย

#### 3\. ⚠️ การตรวจทวนผลลัพธ์ AI (Verify)

AI อาจ "มั่นใจ" ในคำตอบที่ตัวเลขผิดได้ (เรียกว่า hallucination) ดังนั้นทุกครั้งที่ได้ insight จาก AI ให้:

| ขั้นตรวจทาน | ทำยังไง |
| --- | --- |
| เช็คตัวเลขอ้างอิง | กลับไปดูใน Pivot Table/ตารางจริงว่าตัวเลขที่ AI พูดถึงตรงกันไหม |
| เช็คตรรกะ | AI สรุปเหตุผลแบบไหน สมเหตุสมผลกับข้อมูลที่ให้ไปหรือไม่ |
| ถามย้ำ | ถ้าไม่แน่ใจ ถามกลับว่า "ตัวเลขนี้มาจากแถวไหน/คำนวณยังไง" |

### ⚡ Quick Win (ทดสอบได้ใน 5 นาที)

1.  Copy ตาราง Pivot Table สรุปค่าใช้จ่ายแยกตามประเภท (10 แถว) จาก Phase 1
2.  วางในแชท Claude พร้อมข้อความ "นี่คือสรุปค่าใช้จ่ายของฉันรายสัปดาห์ ช่วยบอก insight ที่น่าสนใจ 2 ข้อ"
3.  เช็คว่าตัวเลขที่ Claude พูดถึง ตรงกับที่อยู่ในตารางจริงไหม

✅ ถ้า Claude ให้ insight ที่อ้างอิงตัวเลขถูกต้อง → ผ่าน! ถ้าตัวเลขไม่ตรง → ลองส่งข้อมูลให้ชัดขึ้นแล้วถามใหม่

### 💬 Prompt สำเร็จรูป

ใช้ใน **Claude Chat** สำหรับวิเคราะห์ข้อมูลแบบเต็มรูปแบบ:

```
[Context] นี่คือข้อมูลค่าใช้จ่ายส่วนตัวของฉัน 3 สัปดาห์ แยกตามวันที่/ประเภท/จำนวนเงิน (วางตารางต่อท้าย)
[Task] ช่วยวิเคราะห์ว่ามี pattern หรือความเปลี่ยนแปลงที่น่าสนใจอะไรบ้าง
[Spec] ขอ insight ไม่เกิน 3 ข้อ แต่ละข้อให้อ้างอิงตัวเลข/แถวที่เกี่ยวข้องด้วย
[Constraint] ถ้าข้อมูลไม่พอสรุปบางเรื่อง ให้บอกตรงๆ ว่าข้อมูลไม่พอ ไม่ต้องเดา
```

### 🛠️ Workshop + โจทย์

1.  ส่งข้อมูล Pivot Table (ค่าใช้จ่าย/ยอดขาย จาก Phase 1) ให้ Claude วิเคราะห์ด้วย Prompt ด้านบน
2.  นำ insight ที่ได้ มาตรวจทวนตามตาราง "ขั้นตรวจทาน" — ทำเครื่องหมายว่าแต่ละข้อ "ตรวจแล้วถูก / ผิด / ต้องถามเพิ่ม"
3.  เปรียบเทียบ insight ที่ AI ให้ กับ insight ที่ตัวเองคิดไว้ในสัปดาห์ที่ 5 — เหมือนหรือต่างกันยังไง

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| Prompt | ใช้โครงสร้าง Context/Task/Spec/Constraint ครบ | ถามแบบกว้างๆ ไม่มีโครงสร้าง |
| ได้ Insight | ได้ insight อย่างน้อย 2 ข้อ พร้อมตัวเลขอ้างอิง | ได้คำตอบทั่วไป ไม่มีตัวเลข |
| ตรวจทาน | เทียบ insight กับข้อมูลจริงแล้ว ระบุได้ว่าถูก/ผิด/ต้องถามเพิ่ม | เชื่อผลลัพธ์ AI ทันทีโดยไม่เช็ค |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Claude ตอบกว้างๆ ไม่มีตัวเลข | ส่งคำถามแบบ "ช่วยวิเคราะห์หน่อย" ไม่มี Spec | เพิ่ม Spec ระบุว่าอยากได้กี่ข้อ และต้องอ้างอิงตัวเลข |
| ตัวเลขที่ AI พูดถึงไม่ตรงกับตาราง | ส่งข้อมูลไม่ครบ หรือ AI สรุป/ประมาณค่าเอง | ส่งข้อมูลที่เกี่ยวข้องให้ครบ และขอให้ Claude ระบุแถว/อ้างอิงที่ใช้ |
| เชื่อ insight ผิดเพราะดูน่าเชื่อ | ข้าม step ตรวจทาน | ทุกครั้งที่ได้ insight ให้กลับไปเช็คกับ Pivot Table จริงก่อนใช้งานต่อ |

## 🏁 Phase 2 Summary

✅ สิ่งที่ได้เรียนรู้ทั้งหมด:

-   คำนวณและตีความ Mean, Median, สัดส่วน (%), และ % การเปลี่ยนแปลง (Growth Rate)
-   เลือกและจัดลำดับความสำคัญของ Insight ด้วยหลัก Surprising / Impact / Clarity
-   ใช้ Claude ช่วยวิเคราะห์ข้อมูลด้วย Prompt ที่มีโครงสร้าง พร้อมตรวจทวนผลลัพธ์ก่อนใช้งานจริง

**Deliverables จาก Phase นี้:**

-   🔖 ชิ้นงาน 1 — สรุปสถิติพื้นฐาน (Mean, Median, %, Growth Rate) ของข้อมูลค่าใช้จ่าย พร้อมคำอธิบาย (สัปดาห์ 4)
-   🔖 ชิ้นงาน 2 — Priority Matrix + Headline 3 อันดับจาก Insight ที่พบ (สัปดาห์ 5)
-   🔖 ชิ้นงาน 3 — บทสนทนากับ Claude ที่วิเคราะห์ข้อมูล + บันทึกผลตรวจทาน insight (สัปดาห์ 6)

## 📚 Glossary (คำศัพท์น่ารู้)

| คำไทย | English Term | ความหมายสั้นๆ |
| --- | --- | --- |
| ค่าเฉลี่ย | Mean (Average) | ผลรวมหารด้วยจำนวนข้อมูล |
| ค่ากลาง | Median | ค่าที่อยู่กึ่งกลางเมื่อเรียงข้อมูลแล้ว |
| ค่าผิดปกติ | Outlier | ข้อมูลที่สูง/ต่ำผิดจากกลุ่มอย่างมาก |
| อัตราการเปลี่ยนแปลง | Growth Rate | % การเปลี่ยนแปลงเทียบกับช่วงก่อนหน้า |
| การเล่าเรื่องด้วยข้อมูล | Data Storytelling | การเลือก/จัดลำดับ insight ให้สื่อสารได้ชัดเจน |
| ผลลัพธ์ที่ดูน่าเชื่อแต่ผิด | Hallucination (AI) | กรณีที่ AI ตอบอย่างมั่นใจทั้งที่ข้อมูล/ตัวเลขผิด |
| การตรวจทวน | Verify | การเช็คผลลัพธ์ AI กับข้อมูลจริงก่อนใช้งาน |
