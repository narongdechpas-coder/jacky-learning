## 🛠️ Workshop C — ข้อมูลลูกค้า/การตลาด

**ไฟล์ข้อมูล**: `workshop-c-marketing-data.csv` (48 แถว)

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

ธุรกิจหนึ่งทำการตลาดผ่าน 4 ช่องทาง (Facebook Ads, Google Ads, LINE OA, และลูกค้า Walk-in ที่ไม่ได้มาจากโฆษณา) มีข้อมูลรายสัปดาห์ 12 สัปดาห์ — งานของคุณคือหาว่า "ลงโฆษณาช่องทางไหนคุ้มค่าที่สุด"

### 📂 Data Dictionary

| คอลัมน์ | Data Type | คำอธิบาย |
| --- | --- | --- |
| วันที่ (เริ่มสัปดาห์) | Date | วันจันทร์ของแต่ละสัปดาห์ (12 สัปดาห์) |
| ช่องทาง | Categorical | Facebook Ads / Google Ads / LINE OA / Walk-in |
| ค่าโฆษณา (บาท) | Number | เงินที่ใช้ลงโฆษณาในสัปดาห์นั้น (Walk-in = 0) |
| จำนวนคลิก | Number | จำนวนคนคลิกเข้ามาจากโฆษณา (Walk-in = 0) |
| จำนวนคำสั่งซื้อ | Number | จำนวนคำสั่งซื้อที่เกิดขึ้น |
| ยอดขาย (บาท) | Number | ยอดขายรวมที่มาจากช่องทางนั้น |

### 🛠️ ขั้นตอน Workshop (ทำตาม Pipeline เต็ม + เพิ่มมุมมองธุรกิจ)

1.  **Import ข้อมูล** → ตรวจ Data Type ทุกคอลัมน์
2.  **Formula**: เพิ่ม 2 คอลัมน์คำนวณใหม่ (นี่คือของใหม่ที่ Workshop A/B ไม่มี):
    -   `Conversion Rate (%) = จำนวนคำสั่งซื้อ ÷ จำนวนคลิก × 100`
    -   `ROI (เท่า) = ยอดขาย ÷ ค่าโฆษณา` (สำหรับ Walk-in ข้ามได้ เพราะค่าโฆษณา = 0)
3.  **Pivot Table**: Rows = ช่องทาง, Values = SUM(ค่าโฆษณา), SUM(ยอดขาย), AVERAGE(Conversion Rate)
4.  **สถิติ**: หา Growth Rate ของยอดขายรวมทุกช่องทางจากสัปดาห์ 1 เทียบสัปดาห์ 12
5.  **เลือก Insight**: ใช้ Priority Matrix — เช่น "ช่องทางไหน ROI สูงสุด", "ช่องทางไหน Conversion Rate ต่ำเกินไปจนอาจไม่คุ้ม"
6.  **AI ช่วยวิเคราะห์**: ส่ง Pivot Table (รวม ROI/Conversion Rate) ให้ Claude ช่วยแนะนำว่า "ถ้ามีงบโฆษณาเพิ่ม ควรเพิ่มช่องทางไหนก่อน" พร้อมตรวจทวนตัวเลข
7.  **เลือกกราฟ**: ทำ Bar Chart เปรียบเทียบ ROI ต่อช่องทาง และ Scatter Plot ระหว่าง "ค่าโฆษณา" (X) กับ "ยอดขาย" (Y) เพื่อดูความสัมพันธ์
8.  **Dashboard**: ทำ Dashboard สรุป ROI/Conversion Rate ต่อช่องทาง พร้อม Filter เลือกช่วงสัปดาห์

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| คอลัมน์คำนวณใหม่ | Conversion Rate และ ROI คำนวณถูกสูตร ไม่มี error ที่ Walk-in | สูตร error ตอนค่าโฆษณา = 0 (ไม่ได้ใช้ `IFERROR`) |
| Pivot Table | สรุป ROI/Conversion Rate ต่อช่องทางถูกต้อง เทียบได้ว่าช่องทางไหนดีกว่า | ใช้ SUM กับ Conversion Rate/ROI (ต้องใช้ AVERAGE ไม่ใช่ SUM) |
| Insight + Dashboard | ระบุช่องทางที่ ROI สูงสุด/ต่ำสุด พร้อมตัวเลข และมี Bar+Scatter ใน Dashboard | สรุปโดยไม่อ้างอิงตัวเลข ROI/Conversion Rate |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| `#DIV/0!` ที่แถว Walk-in | ค่าโฆษณา = 0 แล้วหารเพื่อหา ROI | ใช้ `=IFERROR(ยอดขาย/ค่าโฆษณา, "N/A")` |
| Pivot Table ของ ROI ใช้ SUM แล้วค่าผิดเพี้ยน | ROI เป็นค่าเฉลี่ย/อัตรา ไม่ควรบวกกันตรงๆ | เปลี่ยน Values เป็น AVERAGE หรือคำนวณ ROI ใหม่จาก SUM(ยอดขาย)/SUM(ค่าโฆษณา) ใน Pivot |
| Scatter Plot จุดกระจายไม่มีแนวชัด เพราะรวม Walk-in | Walk-in มีค่าโฆษณา = 0 เสมอ ทำให้จุดทับกันที่แกน X=0 | กรอง Walk-in ออกจาก Scatter Plot นี้ (วิเคราะห์แยกเป็นอีกกราฟ) |

### 🎯 Bonus Challenge

ลองถาม Claude ว่า "ถ้างบโฆษณารวมเท่าเดิม แต่ย้ายงบจากช่องทางที่ ROI ต่ำสุดไปช่องทางที่ ROI สูงสุดทั้งหมด คาดว่ายอดขายรวมจะเปลี่ยนไปประมาณเท่าไหร่" — เป็นตัวอย่างการใช้ AI ช่วย "จำลองสถานการณ์" (what-if) แบบคร่าวๆ แล้วใช้วิจารณญาณตรวจทานสมมติฐานที่ AI ใช้

## 📚 Glossary เพิ่มเติม (คำศัพท์น่ารู้)

| คำไทย | English Term | ความหมายสั้นๆ |
| --- | --- | --- |
| อัตราการเปลี่ยนเป็นลูกค้า | Conversion Rate | % ของคนที่คลิกแล้วซื้อจริง (คำสั่งซื้อ ÷ คลิก) |
| ผลตอบแทนจากการลงทุน | ROI (Return on Investment) | ยอดขายที่ได้ เทียบกับเงินที่ลงทุนไป (ยอดขาย ÷ ค่าโฆษณา) |
| การจำลองสถานการณ์ | What-if Analysis | การลองเปลี่ยนตัวแปรหนึ่ง เพื่อดูผลลัพธ์ที่อาจเกิดขึ้น |
| ค่าผิดปกติ (ทบทวน) | Outlier | ข้อมูลที่สูง/ต่ำผิดจากกลุ่มมาก เช่น "ค่าเทอม" ใน Workshop B |
