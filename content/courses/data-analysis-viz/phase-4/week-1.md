## 🛠️ Workshop A — ยอดขายร้านกาแฟ 3 สาขา

**ไฟล์ข้อมูล**: `workshop-a-sales-data.csv` (96 แถว)

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

สมมติว่าคุณเป็นเจ้าของร้านกาแฟที่มี 3 สาขา ทุกสัปดาห์มีรายงานยอดขายแยกตามหมวดหมู่สินค้าส่งมาให้ — งานของคุณคือดูว่า "สาขาไหนทำได้ดี" และ "ควรเพิ่ม/ลดสินค้าหมวดไหน"

### 📂 Data Dictionary

| คอลัมน์ | Data Type | คำอธิบาย |
| --- | --- | --- |
| วันที่ (เริ่มสัปดาห์) | Date | วันจันทร์ของแต่ละสัปดาห์ (8 สัปดาห์) |
| สาขา | Categorical | สาขา A / สาขา B / สาขา C |
| หมวดหมู่สินค้า | Categorical | กาแฟ / ชา-นม / เบเกอรี่ / เครื่องดื่มเย็น |
| จำนวนที่ขาย | Number | จำนวนชิ้นที่ขายได้ในสัปดาห์นั้น |
| ราคาต่อหน่วย (บาท) | Number | ราคาเฉลี่ยต่อชิ้น |
| ยอดขาย (บาท) | Number | \= จำนวนที่ขาย × ราคาต่อหน่วย |

### 🛠️ ขั้นตอน Workshop (ทำตาม Pipeline เต็ม)

1.  **Import ข้อมูล** → Google Sheets (`File > Import > Upload`) → ตรวจ Data Type ทุกคอลัมน์ตามหลักสัปดาห์ 1
2.  **Formula**: หา `ยอดขายรวมทั้งหมด`, `ยอดขายรวมต่อสาขา` (ใช้ `SUMIF`), `ยอดขายรวมต่อหมวดหมู่สินค้า`
3.  **Pivot Table**: สร้าง Pivot สรุป `ยอดขาย` โดย Rows = สาขา, Columns = หมวดหมู่สินค้า, Values = SUM
4.  **สถิติ**: คำนวณ `% การเปลี่ยนแปลง` ของยอดขายรวมจากสัปดาห์ 1 เทียบสัปดาห์ 8 (Growth Rate) ของแต่ละสาขา
5.  **เลือก Insight**: ใช้ Priority Matrix เลือก insight 2-3 อันดับ (เช่น "สาขาไหนโตเร็วสุด", "หมวดหมู่ไหนขายดีสุดในแต่ละสาขา")
6.  **AI ช่วยวิเคราะห์**: ส่ง Pivot Table ให้ Claude ช่วยตอบโจทย์ "สาขาไหนควรเพิ่มสต็อกเบเกอรี่" พร้อมตรวจทวนคำตอบกับตัวเลขจริง
7.  **เลือกกราฟ**: ทำ Bar Chart เปรียบเทียบยอดขายแต่ละสาขา และ Line Chart ดูแนวโน้มยอดขายรวมตามสัปดาห์
8.  **Dashboard**: เชื่อม Sheet เข้า Looker Studio ทำ Dashboard 1 หน้า มี Filter เลือกสาขา

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| Pivot Table | สรุปยอดขายแยกสาขา × หมวดหมู่ ถูกต้อง (เช็คผลรวมตรงกับ SUM ทั้งไฟล์) | ตัวเลขไม่ตรง หรือขาดบางสาขา/หมวดหมู่ |
| Insight | ระบุได้ว่าสาขาไหนโตเร็วสุด พร้อม % Growth Rate อ้างอิงตัวเลขจริง | ตอบแบบกะคร่าวๆ ไม่มีตัวเลข |
| Dashboard | มี Bar + Line chart และ Filter เลือกสาขาทำงานได้ | ขาดกราฟใดกราฟหนึ่ง หรือ filter ไม่ทำงาน |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Import CSV แล้วภาษาไทยเป็นตัวอักษรแปลกๆ | Encoding ไม่ตรง (ไฟล์เป็น UTF-8) | ใน Google Sheets ใช้ `File > Import` แล้วเลือก detect automatically มักแก้ได้ ถ้าไม่ได้ลองเปิดผ่าน Google Drive แทน double-click |
| คอลัมน์ "วันที่" เรียงไม่ถูกต้อง | คอลัมน์ถูก import เป็น Text | เลือกคอลัมน์ > Format > Date |
| Pivot Table ยอดรวมไม่ตรงกับ SUM ทั้งไฟล์ | ลืมรวม "ยอดขาย" ทุกสาขา/หมวดหมู่ใน Pivot | เช็คว่า Pivot Table แสดง Grand Total และตรงกับ `=SUM()` ของคอลัมน์ยอดขายทั้งหมด |

### 🎯 Bonus Challenge

ลองคำนวณ "ยอดขายเฉลี่ยต่อหน่วยที่ขาย" ของแต่ละหมวดหมู่ (ยอดขายรวม ÷ จำนวนที่ขายรวม) แล้วเทียบว่าหมวดไหน "ราคาแพงแต่ขายน้อย" vs "ราคาถูกแต่ขายเยอะ" — สรุปว่าร้านควรโปรโมทหมวดไหนเพิ่ม
