## 🛠️ Workshop B — ค่าใช้จ่ายครอบครัว

**ไฟล์ข้อมูล**: `workshop-b-expenses-data.csv` (102 แถว)

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

ครอบครัวหนึ่งมีสมาชิก 4 คน บันทึกค่าใช้จ่ายทุกวันมา 6 สัปดาห์ — งานของคุณคือช่วยดูว่า "ใครใช้เงินหมวดไหนมากที่สุด" และ "ควรปรับงบตรงไหนในเดือนหน้า"

### 📂 Data Dictionary

| คอลัมน์ | Data Type | คำอธิบาย |
| --- | --- | --- |
| วันที่ | Date | วันที่บันทึกรายการ (42 วัน) |
| สมาชิก | Categorical | พ่อ / แม่ / ลูกคนโต / ลูกคนเล็ก |
| ประเภท | Categorical | อาหาร / เดินทาง / ของใช้ในบ้าน / การศึกษา / บันเทิง / สุขภาพ |
| รายการ | Text | รายละเอียดของรายการ (เช่น "ค่าน้ำมัน") |
| จำนวนเงิน (บาท) | Number | จำนวนเงินที่ใช้ในรายการนั้น |

### 🛠️ ขั้นตอน Workshop (ทำตาม Pipeline เต็ม)

1.  **Import ข้อมูล** → ตรวจ Data Type โดยเฉพาะคอลัมน์ "จำนวนเงิน" ว่าเป็น Number จริง
2.  **Formula**: หา `ค่าใช้จ่ายรวมทั้งหมด`, ใช้ `SUMIF`/`COUNTIF` หา `ยอดรวม` และ `จำนวนรายการ` ต่อสมาชิกแต่ละคน
3.  **Pivot Table**: Rows = สมาชิก, Columns = ประเภท, Values = SUM(จำนวนเงิน) — เพื่อดูว่าใครใช้เงินหมวดไหนเท่าไหร่
4.  **สถิติ**: หา Mean และ Median ของค่าใช้จ่ายต่อวัน, หาสัดส่วน (%) ของแต่ละประเภทเทียบกับยอดรวมทั้งหมด
5.  **เลือก Insight**: ใช้ Priority Matrix — เช่น "สมาชิกคนไหนใช้เงินหมวดบันเทิงมากที่สุด", "หมวดไหนคิดเป็นสัดส่วนใหญ่สุดของบ้าน"
6.  **AI ช่วยวิเคราะห์**: ส่งข้อมูลสรุปให้ Claude ช่วยแนะนำว่า "ถ้าอยากลดค่าใช้จ่ายรวม 10% ควรเริ่มจากหมวดไหนของใคร" พร้อมตรวจทวนกับ Pivot Table
7.  **เลือกกราฟ**: ทำ Pie Chart สัดส่วนค่าใช้จ่ายแต่ละประเภท (รวมทั้งบ้าน) และ Bar Chart เปรียบเทียบค่าใช้จ่ายรวมต่อสมาชิก
8.  **Dashboard**: ทำ Dashboard ที่มี Filter เลือก "สมาชิก" เพื่อดูค่าใช้จ่ายเฉพาะคนนั้นได้

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| Pivot Table | สรุปค่าใช้จ่ายแยกสมาชิก × ประเภท ถูกต้อง | มีสมาชิกหรือประเภทขาดหายจาก Pivot |
| สถิติ | คำนวณ Mean/Median/% สัดส่วนได้ และอธิบายความหมายได้ | คำนวณได้แต่ตีความผิด (เช่น สัดส่วนรวมไม่ถึง 100%) |
| Dashboard + Filter | เลือกสมาชิกแล้วกราฟอัปเดตเฉพาะค่าใช้จ่ายของคนนั้น | Filter ไม่ทำงาน หรือกราฟไม่เปลี่ยน |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Pie Chart สัดส่วนค่าใช้จ่ายอ่านยาก | มี 6 ประเภท ใกล้เคียงกันหลายหมวด | ใช้ Bar Chart เรียงจากมากไปน้อยแทน (อ้างอิงสัปดาห์ 7) |
| SUMIF หมวด "การศึกษา" ได้ค่าสูงผิดปกติ | มีรายการ "ค่าเทอม" ที่เป็นค่าใช้จ่ายก้อนใหญ่ครั้งเดียว (outlier) | ใช้ Median ควบคู่กับ Mean เพื่อดูภาพที่ไม่ถูก outlier บิดเบือน |
| Filter เลือกสมาชิกแล้ว Pie Chart ว่าง | Pie Chart ใช้ field "ประเภท" แต่ไม่ได้เชื่อมกับ filter "สมาชิก" | ตรวจสอบว่า chart และ filter ใช้ data source เดียวกัน |
