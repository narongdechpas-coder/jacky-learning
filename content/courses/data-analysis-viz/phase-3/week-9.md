### ⚡ Quick Win (เริ่มต้นใน 5 นาที)

เลือก "ชุดข้อมูลจริง" ที่จะใช้ทำ Final Project — อาจเป็นข้อมูลค่าใช้จ่ายส่วนตัวที่สะสมมาตลอดคอร์ส, ข้อมูลยอดขายจากที่ทำงาน (ถ้ามีและแชร์ได้), หรือข้อมูลตัวอย่างที่ขอ Claude ช่วยสร้างให้

✅ ถ้าเลือกชุดข้อมูลที่มีอย่างน้อย 3 คอลัมน์ (1 เป็นวันที่/เวลา, 1 เป็นหมวดหมู่, 1 เป็นตัวเลข) → พร้อมเริ่ม!

### 💬 Prompt สำเร็จรูป

ใช้ใน **Claude Chat** เพื่อ Review ก่อนนำเสนอจริง:

```
[Context] นี่คือ Insight 3 อันดับ + กราฟที่เลือกใช้ใน Dashboard ของฉัน (อธิบาย/แนบรูปหรือคำอธิบาย)
[Task] ช่วย review ว่า Insight แต่ละข้อ สื่อสารชัดเจนไหม กราฟที่เลือกเหมาะสมไหม
[Spec] ให้ feedback แบบเรียงลำดับ: จุดที่ดีอยู่แล้ว, จุดที่ควรปรับ, คำแนะนำการนำเสนอ (พูดอะไรก่อน-หลัง)
[Constraint] เวลานำเสนอจริงมีประมาณ 3-5 นาที
```

### 🛠️ Workshop + โจทย์ (Final Project)

1.  เลือกชุดข้อมูลจริง (อย่างน้อย 2-3 สัปดาห์ของข้อมูล)
2.  ทำตาม Checklist ข้อ 1-8 ให้ครบ
3.  สร้าง Dashboard ใน Looker Studio 1 หน้า
4.  เตรียมพูดนำเสนอ 3-5 นาที โดยใช้โครงสร้าง:
    -   เริ่มด้วย Insight ที่สำคัญที่สุด (headline)
    -   อธิบายกราฟที่สนับสนุน insight นั้น
    -   ปิดท้ายด้วยสิ่งที่ "ควรทำต่อ" จาก insight ที่เห็น
5.  (ถ้ามีเพื่อน/ทีม) ลองนำเสนอให้คนอื่นฟัง แล้วถามว่าเข้าใจ insight หลักไหมภายใน 1 นาทีแรก

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| Checklist | ทำครบทั้ง 9 ข้อ มีหลักฐาน (ไฟล์ Sheets + Dashboard) | ขาดขั้นตอนใดขั้นตอนหนึ่ง |
| Dashboard | มี Scorecard + กราฟอย่างน้อย 2 ประเภท + Filter control | มีแค่กราฟเดียว หรือไม่มี filter |
| การนำเสนอ | คนฟังเข้าใจ insight หลักภายใน 1 นาทีแรก | ต้องอธิบายซ้ำหลายรอบ คนฟังยังไม่เข้าใจประเด็น |

### 🚨 Common Errors

| Error | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| นำเสนอแล้วคนฟังงง ไม่รู้ประเด็นหลัก | เริ่มด้วยรายละเอียด/ข้อมูลดิบก่อน insight | เริ่มด้วย headline/insight สำคัญที่สุดก่อนเสมอ (อ้างอิงสัปดาห์ 5) |
| Dashboard มีกราฟเยอะเกินไป จนหาจุดสำคัญไม่เจอ | ใส่ทุกกราฟที่ทำได้ ไม่ได้คัดเลือก | ใช้ Priority Matrix คัดเหลือ 3-4 กราฟที่สำคัญที่สุด |
| เวลานำเสนอเกินที่กำหนด | ไม่ได้ลองพูดจับเวลาก่อน | ฝึกพูดจับเวลาอย่างน้อย 1 รอบก่อนนำเสนอจริง |

## 🏁 Phase 3 Summary

✅ สิ่งที่ได้เรียนรู้ทั้งหมด:

-   เลือกกราฟ (Bar/Line/Pie/Scatter) ให้เหมาะกับข้อมูลและประเด็น พร้อมทดลองแบบ Interactive
-   เชื่อม Google Sheets เข้า Looker Studio และสร้าง Dashboard ที่มี Filter control
-   รวมทุกทักษะจาก Phase 1-3 ทำ Final Project วิเคราะห์ข้อมูลจริงและนำเสนอ

**Deliverables จาก Phase นี้:**

-   🔖 ชิ้นงาน 1 — กราฟ 3 แบบใน Google Sheets ตาม Insight ที่เลือก + เปรียบเทียบกราฟผิด/ถูก (สัปดาห์ 7)
-   🔖 ชิ้นงาน 2 — Dashboard ใน Looker Studio ที่เชื่อมข้อมูลจริง พร้อม Filter control (สัปดาห์ 8)
-   🔖 ชิ้นงาน 3 — Final Project ฉบับสมบูรณ์ (ข้อมูล + วิเคราะห์ + Dashboard + สไลด์/บทพูดนำเสนอ) (สัปดาห์ 9)

## 🎓 Course Wrap-up

ตลอด 9 สัปดาห์ ผู้เรียนได้ฝึกครบ Pipeline การวิเคราะห์ข้อมูล:

**จัดข้อมูล (Phase 1) → วิเคราะห์ & เลือก Insight (Phase 2) → นำเสนอด้วย Visualization (Phase 3)**

Deliverable สุดท้าย = ไฟล์ข้อมูลที่จัดเรียบร้อย + Pivot Table/สถิติ + Dashboard ใน Looker Studio + การนำเสนอ insight ที่ชัดเจน — พร้อมนำไปปรับใช้กับข้อมูลจริงในงาน/ชีวิตประจำวันต่อได้เลย 🎉

## 📚 Glossary (คำศัพท์น่ารู้)

| คำไทย | English Term | ความหมายสั้นๆ |
| --- | --- | --- |
| กราฟแท่ง | Bar Chart | กราฟเปรียบเทียบค่าระหว่างหมวดหมู่ |
| กราฟเส้น | Line Chart | กราฟแสดงแนวโน้มตามเวลา |
| กราฟวงกลม | Pie Chart | กราฟแสดงสัดส่วนของทั้งหมด |
| กราฟจุดกระจาย | Scatter Plot | กราฟแสดงความสัมพันธ์ระหว่างตัวเลข 2 ชุด |
| แดชบอร์ด | Dashboard | หน้ารวมกราฟ/ข้อมูลสำคัญในที่เดียว |
| ตัวกรอง | Filter Control | ตัวเลือกให้คนดู Dashboard กรองข้อมูลเอง |
| ตัวเลขสรุปเดี่ยว | Scorecard | กล่องแสดงตัวเลขสรุปเดียว เช่น ยอดรวม |
