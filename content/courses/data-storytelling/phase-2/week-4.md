### 😊 Jacky ขออธิบายเพิ่มเติมว่า

**ทำไม Design ถึงสำคัญในสไลด์?**

ลองนึกถึงร้านอาหาร 2 ร้าน อาหารอร่อยพอๆ กัน แต่ร้านหนึ่งจัดจาน สะอาด มีดอกไม้ตกแต่ง อีกร้านวางอาหารในชามพลาสติก — คนส่วนใหญ่จะรู้สึกว่าอาหารของร้านแรก "อร่อยกว่า" ทั้งๆ ที่รสชาติเหมือนกัน

สไลด์ก็เหมือนกัน เนื้อหาเดิม แต่ Design ดีกว่า คนฟังจะเชื่อถือและเข้าใจได้ดีกว่า

**กฎ 4 ข้อของ Design ที่ดี (C.A.R.P.):**

```
C — Contrast (ความตัดกัน)
    ข้อความสำคัญต้องโดดเด่นออกมา
    เช่น ตัวเลขหลักใช้ Font Size ใหญ่กว่า 2 เท่า

A — Alignment (การจัดวาง)
    ทุกอย่างต้องตรงแนว ไม่วางมั่วซั่ว
    ใช้ Format → Align ใน Google Slides

R — Repetition (ความสม่ำเสมอ)
    ใช้ Font, สี, Style เดิมตลอด
    อย่าเปลี่ยน Font กลางสไลด์

P — Proximity (ความใกล้ชิด)
    ข้อมูลที่เกี่ยวกันให้วางใกล้กัน
    ข้อมูลต่างกันให้เว้นระยะ
```

### 🖊️ Typography — ตัวอักษรที่ใช้ในสไลด์

**กฎ Font สำหรับ Slides:**

```
Heading (หัวข้อ):   ≥ 36pt  — อ่านได้จากระยะไกล
Subheading:         ≥ 28pt
Body Text:          ≥ 24pt  — อย่างน้อยที่สุด
Caption/Label:      ≥ 18pt

Font ที่อ่านง่ายบนสไลด์ (แนะนำ):
→ Google Fonts: Noto Sans Thai (ภาษาไทย), Inter, Roboto
→ ใช้ Font ไม่เกิน 2 แบบใน 1 Deck
→ Heading: Font มีบุคลิก / Body: Font อ่านง่าย
```

**วิธีเพิ่ม Google Fonts ใน Google Slides:**

```
1. คลิกที่ Font Name dropdown
2. คลิก "More fonts..."
3. ค้นหา Font ที่ต้องการ
4. คลิก Add
```

### 🎨 Color — ใช้สีอย่างมีความหมาย

**โครงสี 3-2-1 สำหรับสไลด์:**

```
3 สีหลัก (Base): สีพื้นหลังและข้อความ (60%)
2 สีรอง (Support): สีสำหรับกราฟและองค์ประกอบ (30%)
1 สีเน้น (Accent): สีสำหรับข้อมูลสำคัญที่สุด (10%)

ตัวอย่าง:
พื้นหลังขาว + ข้อความเทาเข้ม (Base)
กราฟสีน้ำเงินและสีเขียวอ่อน (Support)
ตัวเลขสำคัญสีส้มสด (Accent) ← ใช้น้อยๆ
```

**สีที่ใช้ในบริบทธุรกิจ:**

```
น้ำเงินเข้ม/กรมท่า → ความน่าเชื่อถือ, มืออาชีพ
เขียว             → เติบโต, บวก, สำเร็จ
แดง               → ลด, ลบ, เตือน (ใช้น้อย)
ส้ม               → เน้นสำคัญ, Action
เทา               → ข้อมูลรอง, บริบท
```

**Prompt 1 — ให้ AI แนะนำ Color Palette**

```
[Context] ฉันกำลังสร้างสไลด์นำเสนองานใน [ประเภทบริษัท/อุตสาหกรรม]
ต่อ [Audience: หัวหน้า/ทีม/ลูกค้า]
[Task] แนะนำ Color Palette ที่เหมาะสม
[Spec]
- บอก Hex Code ของแต่ละสี
- อธิบายว่าทำไมสีนี้ถึงเหมาะกับบริบทนี้
- แนะนำ 3 ตัวเลือก: Professional, Modern, Warm
[Constraint] แต่ละ Palette ต้องมี 3-2-1 (Base-Support-Accent)
```

---

**Prompt 2 — ตรวจสอบ Design ของสไลด์**

```
[Context] ฉันสร้างสไลด์แล้ว อยากให้ตรวจ Design
[Task] ตรวจสอบตาม CARP Principle
[Spec]
เนื้อหาสไลด์: [อธิบายสไลด์]
Font ที่ใช้: [Font + Size]
สีที่ใช้: [สีหลัก]

ตรวจ:
- Contrast: ตัดกันพอไหม?
- Alignment: จัดวางตรงแนวไหม?
- Repetition: Consistent ทุกหน้าไหม?
- Proximity: ข้อมูลที่เกี่ยวกันอยู่ใกล้กันไหม?
```

### 🛠️ Workshop — "Redesign สไลด์ให้มืออาชีพ"

> 🏷️ **Tool ที่ใช้:** Google Slides + Claude Chat ⏱️ **เวลาโดยประมาณ:** 2 ชั่วโมง

**โจทย์:** นำสไลด์ 5–7 หน้าจากสัปดาห์ 3 มา Redesign ทั้งหมดโดยใช้หลัก CARP + Color Palette ที่เลือก + Font ที่เหมาะสม

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| ใช้ Font ไม่เกิน 2 แบบ | สม่ำเสมอทุกหน้า | แต่ละหน้า Font ต่างกัน |
| มีสีเน้นแค่ 1 สี ใช้เฉพาะจุดสำคัญ | Accent ใช้ < 10% | ทุกอย่างเป็นสีสด |
| ทุกข้อความ Align ตรงแนว | จัดระเบียบสะอาด | วางมั่วซั่ว |
| Font Size ≥ 24pt สำหรับ Body | อ่านได้จากระยะไกล | ตัวเล็กเกินไป |

### 🚨 Common Errors

| ปัญหาที่เจอ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| สไลด์มีสีเยอะเกินไป | อยากให้สวยโดยใช้สีหลายสี | ยึดหลัก 3-2-1 สีเท่านั้น |
| Font เล็กเกินไป | พยายามยัดข้อความเยอะ | ตัดข้อความออก ขยาย Font |
| สไลด์แต่ละหน้า Style ต่างกัน | ไม่ได้ใช้ Template เดียวกัน | ใช้ Slide Master ใน Google Slides |
