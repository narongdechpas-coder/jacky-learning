### ⚡ Quick Win (ทดสอบก่อนเริ่ม 5 นาที)

เปิดสไลด์จากสัปดาห์ที่ 1 แล้วถามตัวเองว่า:

```
"ถ้าหัวหน้าดูสไลด์นี้ 10 วินาที
แล้วถามว่า 'แล้วยังไง?' — ฉันตอบได้ทันทีไหม?"
```

**ถ้าตอบได้ทันที = Key Message ชัดแล้ว ✅** ถ้าตอบไม่ได้ทันที = สัปดาห์นี้จะแก้ปัญหานี้

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

**ทำไมต้องรู้จัก Audience ก่อน?**

ลองนึกถึงการอธิบายว่า "Internet คืออะไร" ให้คนสามกลุ่มฟัง:

```
ให้เด็ก 5 ขวบ:
"Internet เหมือนถนนใหญ่มากๆ ที่คอมพิวเตอร์ทุกเครื่องใช้คุยกัน"

ให้คุณพ่อคุณแม่:
"Internet คือระบบที่ทำให้เราเช็ก Email ดู YouTube และช้อปปิ้งออนไลน์ได้"

ให้วิศวกร IT:
"Internet คือ Global Network ที่ใช้ TCP/IP Protocol เชื่อมต่ออุปกรณ์"
```

เนื้อหาเดิม แต่เล่าต่างกันทั้งหมด — นั่นคือ Audience Analysis

**4 คำถามที่ต้องถามก่อนสร้างสไลด์ทุกครั้ง:**

```
1. เขารู้อะไรอยู่แล้ว?
   → อย่าอธิบายสิ่งที่เขารู้อยู่แล้ว เสียเวลาทั้งคู่

2. เขาอยากได้อะไรจากการนำเสนอนี้?
   → ข้อมูล? การตัดสินใจ? การอนุมัติ?

3. เขากังวลเรื่องอะไร?
   → งบประมาณ? เวลา? ความเสี่ยง? ทรัพยากร?

4. เขาจะทำอะไรหลังฟังจบ?
   → ต้องการให้เขา Approve? ลงมือทำ? แค่รับรู้?
```

### 🎯 Key Message — หัวใจของการนำเสนอ

**Key Message ที่ดีต้องผ่านทั้ง 3 ข้อนี้:**

```
Test 1: "So What?" Test
→ พูด Key Message แล้วถามว่า "แล้วยังไง?"
→ ถ้าตอบได้ = ผ่าน
→ ถ้าตอบไม่ได้ = ยังไม่ใช่ Key Message

Test 2: "Bumper Sticker" Test
→ Key Message ต้องพูดได้ใน 10 คำหรือน้อยกว่า
→ เหมือนสโลแกนที่ติดท้ายรถได้

Test 3: "Action" Test
→ Key Message ควรบอกได้ว่า "ใครควรทำอะไร"
→ ไม่ใช่แค่บอกข้อเท็จจริง
```

**ตัวอย่าง Key Message ที่ดีและไม่ดี:**

```
❌ ไม่ดี:
"ยอดขายไตรมาส 3 ลดลง 15%"
→ แค่บอกข้อเท็จจริง ไม่มี Action

✅ ดี:
"ยอดขายลด 15% เพราะสต็อกหมด — ต้องเพิ่ม Order ก่อน Q4"
→ มีปัญหา มีสาเหตุ มี Action ที่ชัดเจน
```

### 📐 Pyramid Principle — วิธีจัดเรียงเนื้อหา

Barbara Minto นักที่ปรึกษา McKinsey คิดค้นวิธีนี้ในปี 1970 ยังใช้อยู่ทั่วโลก:

```
        🔺 Key Message (บอกก่อนเลย)
       /   \
   เหตุผล1  เหตุผล2  เหตุผล3
   /    \   /    \   /    \
หลักฐาน หลักฐาน หลักฐาน หลักฐาน

กฎ: บอกสรุปก่อน แล้วค่อยอธิบาย
ไม่ใช่: อธิบายยาวๆ แล้วค่อยสรุป
```

### 💬 Prompt สำเร็จรูป

> 🏷️ **ใช้ใน:** `Claude Chat`

---

**Prompt 1 — วิเคราะห์ Audience**

```
[Context] ฉันต้องนำเสนอเรื่อง [หัวข้อ] ต่อ [บอกว่าใคร]
[Task] ช่วยวิเคราะห์ Audience และแนะนำวิธีนำเสนอ
[Spec]
วิเคราะห์:
1. สิ่งที่เขารู้อยู่แล้ว (อย่าอธิบายซ้ำ)
2. สิ่งที่เขาอยากได้จากการนำเสนอนี้
3. ความกังวลที่น่าจะมี
4. คำถามที่น่าจะถามหลังฟังจบ
5. สิ่งที่ควรเน้น vs ควรตัดออก
[Constraint] ตอบตามบริบทจริงๆ ไม่ใช่ทั่วไป
```

---

**Prompt 2 — สร้าง Key Message ที่แข็งแกร่ง**

```
[Context] ฉันมีข้อมูลนี้ที่จะนำเสนอ:
[วางข้อมูลหรือประเด็นที่มี]
ผู้ฟัง: [บอกว่าใคร]

[Task] ช่วยสร้าง Key Message ที่ผ่าน 3 Tests:
1. So What Test — มีความหมายต่อผู้ฟัง
2. Bumper Sticker Test — สั้นกระชับพูดได้ใน 10 คำ
3. Action Test — บอกว่าใครควรทำอะไร

[Constraint]
สร้างมา 3 ตัวเลือก ให้ฉันเลือก
อธิบายว่าแต่ละตัวเน้นจุดต่างกันยังไง
```

---

**Prompt ฉุกเฉิน — Key Message ยังไม่ชัด**

```
นี่คือ Key Message ที่ฉันคิดไว้:
"[Key Message ของฉัน]"

ช่วยทดสอบว่าผ่านหรือไม่ผ่านแต่ละ Test:
- So What Test ✅/❌
- Bumper Sticker Test ✅/❌
- Action Test ✅/❌

ถ้าไม่ผ่าน Test ไหน ช่วยแนะนำวิธีปรับด้วย
```

### 🛠️ Workshop — "ปรับสไลด์ให้ตรง Audience"

> 🏷️ **Tool ที่ใช้:** Google Slides + Claude Chat ⏱️ **เวลาโดยประมาณ:** 2 ชั่วโมง

**โจทย์ / Assignment:**

นำสไลด์จากสัปดาห์ 1 มาปรับใหม่ทั้งหมดโดยใช้ Audience Analysis และ Key Message ที่ชัดเจน

---

**Prompt สำเร็จรูป — ใช้ใน `Claude Chat`**

```
=== Step 1: Audience Analysis ===
ใช้ Prompt 1 ด้านบน กำหนด Audience ให้ชัดเจน
(เช่น "นำเสนอต่อ Manager ที่ไม่รู้รายละเอียด
แต่สนใจผลกระทบต่องบประมาณ")

=== Step 2: สร้าง Key Message ===
ใช้ Prompt 2 ด้านบน สร้าง 3 ตัวเลือก
เลือก 1 ตัวที่ดีที่สุด

=== Step 3: ปรับสไลด์ใน Google Slides ===
[Context] นี่คือ Key Message ของฉัน: [ใส่ Key Message]
Audience คือ: [ใส่ Audience]

[Task] ช่วยแนะนำว่าสไลด์แต่ละหน้าควรมีอะไร
[Spec]
สไลด์ปัจจุบันมี: [อธิบายเนื้อหาแต่ละหน้า]

ช่วยบอก:
1. หน้าไหนควรตัดออก (ไม่ตรง Audience)
2. หน้าไหนควรปรับข้อความ
3. ควรเพิ่มหน้าอะไร
4. หน้าแรกควรพูดอะไรเพื่อดึงความสนใจ
```

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| มี Key Message ที่ผ่าน 3 Tests | บอกได้ใน 10 คำ มี Action | ยังยาวหรือไม่มี Action |
| สไลด์สอดคล้องกับ Audience | เนื้อหาตรงกับสิ่งที่เขาอยากรู้ | มีข้อมูลที่ Audience ไม่สน |
| Slide 1 ดึงความสนใจได้ทันที | ดูแล้วอยากฟังต่อ | ดูแล้วง่วงนอน |
| ผู้ฟังรู้ว่าต้องทำอะไรหลังฟังจบ | Action ชัดเจน | ไม่มี Next Step |

### 🚨 Common Errors

| ปัญหาที่เจอ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Key Message ยาวเกินไป | พยายามใส่ทุกประเด็น | เลือกแค่ 1 ประเด็นสำคัญที่สุด |
| สไลด์ยังมีข้อมูลที่ Audience ไม่สน | ยึดติดกับข้อมูลที่หามา | ถามตัวเองว่า "Audience สนใจเรื่องนี้ไหม?" |
| ไม่รู้จัก Audience ดีพอ | ไม่เคยคุยกับคนฟัง | ถามเขาโดยตรงหรือถาม Claude ช่วยสมมติ |
