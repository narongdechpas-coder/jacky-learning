### 😊 Jacky ขออธิบายเพิ่มเติมว่า

**Gemini ใน Google Slides ทำอะไรได้บ้าง?**

ลองนึกว่า Gemini คือ "ผู้ช่วยฉลาดๆ" ที่นั่งอยู่ข้างๆ ตอนเราสร้างสไลด์ เราพูดกับมันได้เป็นภาษาไทย แล้วมันจะช่วย:

```
สิ่งที่ Gemini ทำได้ใน Google Slides:
✅ สร้างสไลด์ใหม่จากคำอธิบาย
✅ เขียนเนื้อหาใส่สไลด์
✅ สรุปข้อความที่ยาวเกินไป
✅ ปรับโทนการเขียน (ทางการ/ไม่ทางการ)
✅ แนะนำรูปภาพที่เหมาะสม
✅ สร้าง Speaker Notes

สิ่งที่ Gemini ยังทำไม่ได้ดี:
❌ ออกแบบ Visual ที่สวยงามให้ทันที
❌ วิเคราะห์ข้อมูลซับซ้อน
❌ รู้บริบทธุรกิจของบริษัทเรา (ต้องบอกมันเอง)
```

**ความต่างระหว่าง Claude Chat กับ Gemini ใน Slides:**

```
Claude Chat:
→ ใช้เพื่อ "คิด" และ "วางแผน"
→ ช่วยโครงสร้าง SCR, Key Message, Outline
→ ทำงานนอก Google Slides

Gemini ใน Slides:
→ ใช้เพื่อ "สร้าง" โดยตรงใน Slides
→ สร้างสไลด์, เขียนเนื้อหา, สรุปข้อความ
→ ทำงานอยู่ใน Google Slides เลย

วิธีที่ดีที่สุด:
Claude Chat วางแผน → Gemini ใน Slides ลงมือสร้าง
```

### 🔧 วิธีใช้ Gemini ใน Google Slides

**3 วิธีเรียก Gemini:**

```
วิธีที่ 1: ไอคอน ✨ ใน Toolbar
→ คลิกแล้วพิมพ์คำสั่ง

วิธีที่ 2: Extensions → Gemini for Workspace
→ เปิด Sidebar Gemini

วิธีที่ 3: คลิกขวาที่ Text Box → "Help me write"
→ Gemini ช่วยเขียนหรือปรับข้อความ
```

### 📝 Prompt Templates สำหรับ Gemini ใน Slides

**Prompt 1 — สร้างสไลด์ใหม่ทั้งชุด**

```
สร้างสไลด์สำหรับนำเสนอเรื่อง [หัวข้อ]
ต่อ [Audience]
มีทั้งหมด [X] หน้า ดังนี้:
หน้า 1: [เนื้อหา]
หน้า 2: [เนื้อหา]
หน้า 3: [เนื้อหา]
โทนการเขียน: [ทางการ/มืออาชีพ/กระชับ]
```

**Prompt 2 — ปรับข้อความที่มีอยู่**

```
ปรับข้อความนี้ให้:
- กระชับขึ้น ไม่เกิน 3 bullet points
- อ่านเข้าใจได้ใน 5 วินาที
- เหมาะกับผู้บริหารที่ไม่มีเวลา

ข้อความเดิม: [วางข้อความ]
```

**Prompt 3 — สร้าง Speaker Notes**

```
สร้าง Speaker Notes สำหรับสไลด์นี้
เนื้อหาสไลด์: [อธิบายเนื้อหา]
เวลาที่มี: [X นาที/สไลด์]
โทน: [เป็นทางการ/เป็นกันเอง]
รวม: ประเด็นที่อยากเน้น + ตัวอย่างที่อาจยก
```

**Prompt 4 — ตรวจสอบและปรับปรุง**

```
ตรวจสอบสไลด์นี้และบอกว่า:
1. Key Message ชัดเจนไหม?
2. มีข้อมูลมากหรือน้อยเกินไปไหม?
3. ควรปรับอะไรเพื่อให้ [Audience] เข้าใจได้ดีขึ้น?

เนื้อหาสไลด์: [อธิบายหรือวางข้อความ]
```

### 💬 Prompt สำเร็จรูป

> 🏷️ **Prompt วางแผน: ใช้ใน `Claude Chat`** 🏷️ **Prompt สร้างสไลด์: ใช้ใน `Gemini ใน Google Slides`**

---

**Prompt วางแผนก่อน (ใช้ใน Claude Chat):**

```
[Context] ฉันต้องสร้างสไลด์นำเสนอเรื่อง [หัวข้อ]
ต่อ [Audience] ใช้เวลา [X นาที]
Key Message: [Key Message จากสัปดาห์ที่ 2]

[Task] ช่วยสร้าง Slide Outline ที่ละเอียด
[Spec]
สร้าง Outline โดยระบุทุกสไลด์:
- หมายเลขสไลด์
- ชื่อสไลด์ (Slide Title)
- เนื้อหาหลัก 2-3 ประเด็น
- ประเภทของ Visual ที่ควรใช้ (Chart/Image/Text/Data)
- เวลาที่ควรพูด

[Constraint]
- ทุกสไลด์ต้องสนับสนุน Key Message
- สไลด์แรกต้องดึงความสนใจทันที
- สไลด์สุดท้ายต้องมี Clear Call to Action
```

---

**Prompt สร้างสไลด์จริง (ใช้ใน Gemini ใน Slides):**

```
สร้างสไลด์นำเสนอเรื่อง [หัวข้อ]
สำหรับ [Audience]
มี [X] สไลด์ตามโครงสร้างนี้:

สไลด์ 1: [ชื่อ + เนื้อหาโดยย่อ]
สไลด์ 2: [ชื่อ + เนื้อหาโดยย่อ]
สไลด์ 3: [ชื่อ + เนื้อหาโดยย่อ]

โทนการเขียน: มืออาชีพ กระชับ อ่านง่าย
ภาษา: ภาษาไทย
```

### 🛠️ Workshop — "สร้างสไลด์ครบชุดด้วย AI"

> 🏷️ **วางแผน: `Claude Chat`** → **สร้าง: `Gemini ใน Google Slides`** ⏱️ **เวลาโดยประมาณ:** 2 ชั่วโมง

**โจทย์ / Assignment:**

สร้างสไลด์ครบชุด 5–7 หน้า สำหรับนำเสนองานจริงๆ ของตัวเอง โดยใช้ Claude Chat วางแผนก่อน แล้วใช้ Gemini ใน Slides สร้าง

---

**Checkpoint ก่อนเริ่ม:**

```
✅ มี Key Message ที่ผ่าน 3 Tests แล้ว
✅ รู้ว่า Audience คือใคร
✅ Gemini เปิดใช้งานได้ใน Google Slides
```

---

**Prompt สำเร็จรูป — ขั้นตอนเต็ม**

```
=== ขั้นตอนที่ 1: วางแผนใน Claude Chat (30 นาที) ===
ใช้ Prompt "วางแผนก่อน" ด้านบน
ได้ Outline ละเอียดทุกสไลด์

=== ขั้นตอนที่ 2: สร้างใน Google Slides ด้วย Gemini (45 นาที) ===
เปิด Google Slides ใหม่
คลิก ✨ Gemini
ใช้ Prompt "สร้างสไลด์จริง" โดยใส่ Outline จาก Step 1

=== ขั้นตอนที่ 3: ปรับแต่งทีละสไลด์ (30 นาที) ===
สำหรับสไลด์ที่ยังไม่ดีพอ คลิกขวา → "Help me write"
แล้วใช้ Prompt นี้:

"ปรับข้อความในสไลด์นี้ให้:
- กระชับ อ่านได้ใน 5 วินาที
- เน้น Key Message: [ใส่ Key Message]
- เหมาะกับ [Audience]
ข้อความเดิม: [วางข้อความ]"

=== ขั้นตอนที่ 4: สร้าง Speaker Notes (15 นาที) ===
แต่ละสไลด์ คลิก Speaker Notes → ✨
ใช้ Prompt 3 จากด้านบน
```

---

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| สไลด์ครบ 5–7 หน้า สร้างด้วย Gemini | ใช้ Gemini จริง ไม่ได้พิมพ์เอง | พิมพ์เองทั้งหมด |
| ทุกสไลด์สนับสนุน Key Message | อ่านทุกหน้าแล้วชัดว่าเกี่ยวกัน | บางหน้าดูไม่เกี่ยวกัน |
| ใช้ทั้ง Claude Chat + Gemini Slides | วางแผนใน Claude สร้างใน Gemini | ใช้แค่ Tool เดียว |
| มี Speaker Notes ทุกหน้า | Gemini สร้าง Notes ไว้แล้ว | ไม่มี Notes |
| นำเสนอได้จริงโดยไม่ต้องอ่านสไลด์ | ทดลองพูดตาม Notes แล้วไหลลื่น | ยังต้องอ่านจากสไลด์ |

### 🚨 Common Errors

| ปัญหาที่เจอ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Gemini สร้างเนื้อหาผิดบริบท | Prompt ไม่มีบริบทพอ | เพิ่ม Audience + Key Message ใน Prompt ทุกครั้ง |
| เนื้อหาจาก Gemini ยาวเกินไป | Gemini ชอบเขียนละเอียด | เพิ่ม "ไม่เกิน 3 bullet points" ใน Prompt |
| Gemini ไม่มีในบัญชีที่ใช้ | บัญชี Google ส่วนตัวอาจไม่มี | ใช้บัญชี Workspace หรือใช้ Claude Chat แทน Gemini |

## 🏁 Phase 1 Summary — สิ่งที่ได้เรียนรู้ทั้งหมด

```
✅ เข้าใจหลักการ Data Storytelling ว่าต่างจากการนำเสนอทั่วไปยังไง
✅ ใช้โครงสร้าง SCR (Situation-Complication-Resolution) ได้
✅ วิเคราะห์ Audience ได้ด้วยคำถาม 4 ข้อ
✅ สร้าง Key Message ที่ผ่าน So What / Bumper Sticker / Action Tests
✅ รู้หลัก Pyramid Principle — บอกสรุปก่อน แล้วค่อยอธิบาย
✅ ใช้ Gemini ใน Google Slides สร้างสไลด์จาก Prompt ได้
✅ รู้ความต่างระหว่าง Claude Chat กับ Gemini ใน Slides
✅ สร้าง Speaker Notes ด้วย AI ได้
```

**Deliverables (ชิ้นงาน) จาก Phase 1:**

-   📄 **สไลด์ SCR** — 3 หน้า เล่าเรื่องจากตัวเลข (สัปดาห์ 1)
-   🎯 **สไลด์ปรับตาม Audience** — มี Key Message ที่ผ่าน 3 Tests (สัปดาห์ 2)
-   🤖 **สไลด์ครบชุด 5–7 หน้า** — สร้างด้วย Claude + Gemini (สัปดาห์ 3)
