### 😊 Jacky ขออธิบายเพิ่มเติมว่า

**Data Storytelling คืออะไร?**

ลองนึกถึงครูที่สอนสนุกที่สุดในชีวิต กับครูที่อ่านหนังสือให้ฟังอย่างเดียว ครูที่สนุกไม่ได้รู้มากกว่า แต่เขา "เล่าเรื่อง" ได้ดีกว่า

Data Storytelling คือทักษะเดียวกันนั้น แต่ใช้กับข้อมูล แทนที่จะโยนตัวเลขให้คนดูงงๆ เราเปลี่ยนมันเป็นเรื่องราวที่คนฟังเข้าใจและรู้สึกว่า "อ๋อ!" ได้

```
❌ แบบที่ไม่ดี:
"ยอดขายไตรมาส 1 = 2.3M, ไตรมาส 2 = 2.1M,
ไตรมาส 3 = 1.8M, ไตรมาส 4 = 2.7M"

✅ แบบ Data Storytelling:
"ยอดขายเราลดลงติดต่อกัน 2 ไตรมาส
จนกระทั่งเราเปิดช่องทางออนไลน์ในไตรมาส 4
ยอดขายกระโดดขึ้น 50% — นี่คือสัญญาณว่าเราควรทุ่มกับออนไลน์มากขึ้น"
```

**โครงสร้างเรื่องที่ดีที่สุดในโลก — มีแค่ 3 ส่วน:**

```
1. SITUATION (สถานการณ์)
   "ตอนนี้เรากำลังเผชิญกับ..."
   → บอกบริบทและปัญหา

2. COMPLICATION (ความซับซ้อน)
   "แต่ที่น่าสนใจคือ..."
   → บอก Insight หรือสิ่งที่ค้นพบ

3. RESOLUTION (ทางออก)
   "ดังนั้นเราควร..."
   → บอก Action ที่ควรทำ
```

### 🖥️ Google Slides — ส่วนต่างๆ ที่ต้องรู้จัก

```
Interface หลัก:
┌─────────────────────────────────────────┐
│ Menu Bar: File, Edit, View, Insert...   │
├──────┬──────────────────────────────────┤
│Slide │                                  │
│Panel │     พื้นที่แก้ไขสไลด์หลัก        │
│(ซ้าย)│         (ตรงกลาง)                │
│      │                                  │
└──────┴──────────────────────────────────┘

สิ่งที่ต้องรู้วันแรก:
→ Ctrl+M (Mac: Cmd+M)    = เพิ่มสไลด์ใหม่
→ Ctrl+D                 = Duplicate สไลด์
→ Ctrl+Z                 = Undo
→ คลิกขวาที่ Slide Panel = Insert / Delete / Duplicate
→ Format → Slide Settings = เปลี่ยนขนาดสไลด์
```

**ขนาดสไลด์มาตรฐาน:**

```
16:9  (1920×1080px) → นำเสนอบนจอ Monitor/Projector ✅ แนะนำ
4:3   (1024×768px)  → เก่า ไม่นิยมแล้ว
Custom              → ถ้าต้องพิมพ์ออกมาเป็นกระดาษ A4
```

### 📐 หลัก 1-3-5 — กฎง่ายๆ สำหรับสไลด์ที่อ่านได้

```
1 สไลด์   = 1 ความคิดหลัก
3 ประเด็น = จำนวนสูงสุดของ Bullet Point ใน 1 สไลด์
5 วินาที  = เวลาที่คนดูควรเข้าใจสไลด์ได้โดยไม่ต้องอ่านทั้งหมด

ถ้าสไลด์ 1 หน้าต้องการเวลามากกว่า 5 วินาทีในการทำความเข้าใจ
→ แสดงว่ามีข้อมูลมากเกินไป ต้องแตกออกเป็นหลายหน้า
```

### 💬 Prompt สำเร็จรูป

> 🏷️ **ใช้ใน:** `Claude Chat` หรือ `Gemini` ที่ gemini.google.com 💡 สัปดาห์นี้ใช้ Claude Chat ก่อนเพื่อฝึกคิดโครงสร้าง

---

**Prompt 1 — ฝึกคิดโครงสร้าง SCR**

```
[Context] ฉันต้องนำเสนอข้อมูลนี้ต่อทีม:
[วางข้อมูลหรือตัวเลขที่มี]

[Task] ช่วยจัดโครงสร้างเป็น Situation-Complication-Resolution
[Spec]
- Situation: บริบทที่ผู้ฟังต้องรู้ก่อน
- Complication: สิ่งที่น่าสนใจหรือปัญหาที่พบ
- Resolution: Action ที่แนะนำหรือ Next Step

[Constraint]
- แต่ละส่วนไม่เกิน 2 ประโยค
- ใช้ภาษาที่คนทั่วไปเข้าใจได้ ไม่ใช้ Jargon
```

---

**Prompt 2 — ตรวจสอบ Key Message**

```
[Context] นี่คือสไลด์ที่ฉันสร้าง (อธิบายเนื้อหาสไลด์)
[Task] บอกว่า Key Message ของฉันชัดเจนไหม
[Spec]
ถ้าฟังจบแล้วคนดูถามว่า "แล้วยังไงต่อ?"
แสดงว่า Key Message ยังไม่ชัด

ช่วยบอก:
1. Key Message ที่ได้ยินคืออะไร
2. ชัดเจนพอไหม
3. ถ้าไม่ชัด ควรปรับยังไง
[Constraint] ตอบตรงๆ อย่า Sugarcoat
```

---

**Prompt ฉุกเฉิน — ไม่รู้จะเริ่มต้นเล่าเรื่องยังไง**

```
ฉันมีข้อมูลนี้: [วางข้อมูล]
ต้องนำเสนอต่อ: [บอกว่าใครฟัง เช่น ทีม, หัวหน้า, ลูกค้า]
เวลาที่มี: [X นาที]

ช่วยแนะนำว่าควรเริ่มต้นเล่าเรื่องยังไง
บอกประโยคเปิดที่ดึงความสนใจได้ทันทีด้วย
```

### 🛠️ Workshop — "เล่าเรื่องจากตัวเลข"

> 🏷️ **Tool ที่ใช้:** Google Slides + Claude Chat ⏱️ **เวลาโดยประมาณ:** 2 ชั่วโมง 📋 **ต้องมีก่อนเริ่ม:** Google Account + ข้อมูลตัวเลขอะไรก็ได้

**โจทย์ / Assignment:**

สร้างสไลด์ 3 หน้าที่เล่าเรื่องจากข้อมูลที่มี โดยใช้โครงสร้าง SCR (Situation → Complication → Resolution) หน้าละ 1 ส่วน

---

**Checkpoint ก่อนเริ่ม:**

```
✅ เปิด Google Slides ได้
✅ มีข้อมูลตัวเลขพร้อมแล้ว (จริงหรือ Mock)
✅ เปิด Claude Chat ไว้อีกหน้าต่าง
```

---

**ขั้นตอน Workshop:**

```
Step 1 (15 นาที): วางแผนโครงสร้าง
→ เปิด Claude Chat
→ ใช้ Prompt 1 ด้านบน ใส่ข้อมูลที่มี
→ จดโครงสร้าง SCR ที่ได้

Step 2 (30 นาที): สร้างสไลด์หน้า 1 — Situation
→ เปิด Google Slides ใหม่
→ Title Slide: ชื่อเรื่อง + ชื่อผู้นำเสนอ
→ Slide 2: เล่า Situation ด้วยข้อความสั้นๆ

Step 3 (30 นาที): สร้างสไลด์หน้า 2 — Complication
→ Slide 3: เล่า Complication พร้อมตัวเลขสำคัญ
→ ใส่ตัวเลขให้ใหญ่และชัดเจน

Step 4 (30 นาที): สร้างสไลด์หน้า 3 — Resolution
→ Slide 4: เล่า Resolution พร้อม Next Step
→ ต้องตอบได้ว่า "ผู้ฟังควรทำอะไรหลังจากนี้?"

Step 5 (15 นาที): ตรวจสอบด้วย Prompt 2
→ อธิบายเนื้อหาสไลด์ทั้ง 3 หน้าให้ Claude
→ ถามว่า Key Message ชัดเจนไหม
→ แก้ไขตาม Feedback
```

---

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| มีสไลด์ครบ 3 หน้า (S-C-R) | ครบทุกส่วน | ขาดส่วนใดส่วนหนึ่ง |
| แต่ละหน้ามีแค่ 1 ความคิดหลัก | ชัดเจน ไม่ยัดเยียด | ข้อมูลล้นหน้า |
| Key Message บอกได้ใน 1 ประโยค | พูดได้ทันที | ต้องคิดนาน |
| ผู้ฟังรู้ว่าควรทำอะไรต่อ | มี Action ชัดเจน | จบแล้วงงว่าแล้วยังไง |

### 🚨 Common Errors

| ปัญหาที่เจอ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| สไลด์มีข้อความเยอะมาก | พยายามใส่ทุกอย่าง | ตัดเหลือแค่ประโยคสำคัญที่สุด |
| ไม่รู้จะพูดอะไร | ยังไม่มี Key Message | ใช้ Prompt 1 ก่อน อย่าเปิด Slides เลย |
| สไลด์ดูน่าเบื่อ | ใช้ Template เริ่มต้นของ Google | เรื่องนี้จะเรียนใน Phase 2 สัปดาห์นี้แค่เนื้อหาก่อน |
