### 🏗️ Portfolio สำหรับ Data Storyteller

**สิ่งที่ Portfolio ที่ดีต้องแสดง:**

```
1. ความสามารถด้าน Data
   → แสดง Chart ที่ถูกประเภทและอ่านได้ง่าย

2. ความสามารถด้าน Design
   → แสดง Slide ที่สวยงามและ Consistent

3. ความสามารถด้าน Story
   → แสดง Before/After ที่เห็นพัฒนาการ

4. ความสามารถด้าน AI
   → แสดงว่าใช้ Gemini ช่วยสร้างงานได้ยังไง
```

**วิธีสร้าง Portfolio Deck ง่ายๆ:**

```
สไลด์ 1: Cover — ชื่อ + "Data Storytelling Portfolio"
สไลด์ 2: About — ใครคุณ เรียนมาจากไหน
สไลด์ 3–8: Showcase — เลือกสไลด์ที่ดีที่สุด 3 ชิ้น
            แต่ละชิ้นมี: Before/After + เล่าว่าทำไมถึงดีขึ้น
สไลด์ 9: Key Learning — 3 สิ่งสำคัญที่ได้เรียนรู้
สไลด์ 10: Contact — วิธีติดต่อ
```

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| Portfolio Deck ครบ 10 หน้า | มีทุก Section | ขาด Section |
| มี Before/After ของสไลด์เก่าที่ปรับปรุงแล้ว | เห็นพัฒนาการชัดเจน | ไม่มี Before |
| มี Case Study อย่างน้อย 1 ชิ้น | เล่าเรื่องได้ครบ | มีแค่ชื่อโปรเจกต์ |
| Share Link ส่งให้คนอื่นดูได้ | คนอื่นเปิดได้จาก Link | Link ไม่ทำงาน |
