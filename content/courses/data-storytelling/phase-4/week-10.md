### 😊 Jacky ขออธิบายเพิ่มเติมว่า

**ทำไมต้องนำเสนอจริง ไม่ใช่แค่ส่งไฟล์?**

การส่งไฟล์สไลด์เหมือนส่งสูตรอาหาร การนำเสนอจริงคือการปรุงและเสิร์ฟอาหารนั้น คนอ่านสูตรอาจไม่เข้าใจ แต่คนได้กินจะรู้ทันที — และ Feedback ที่ได้จากการนำเสนอจริงจะปรับปรุงทักษะเราได้เร็วกว่าการนั่งทำคนเดียวมาก

**การเก็บ Feedback อย่างมีระบบ:**

```
3 คำถามที่ต้องถามผู้ฟังหลังนำเสนอเสมอ:

1. "ข้อความหลักที่คุณจำได้คืออะไร?"
   → ตรวจว่า Key Message ถึงผู้ฟังจริงๆ

2. "ส่วนไหนที่เข้าใจได้ยากที่สุด?"
   → หาจุดที่ต้องปรับปรุง

3. "มีอะไรที่อยากรู้เพิ่มเติมไหม?"
   → หาช่องว่างของข้อมูล
```

### 📋 Feedback Form ที่ใช้หลังนำเสนอ

```
แบบสอบถาม Presentation Feedback (กรอกได้ใน 2 นาที)

1. Key Message ที่คุณจำได้จากการนำเสนอนี้คืออะไร?
   [ช่องว่าง]

2. ให้คะแนน 1–5 สำหรับแต่ละด้าน:
   ความชัดเจนของเนื้อหา: ___
   ความสวยงามของสไลด์:  ___
   ความเร็วในการนำเสนอ:  ___
   ตอบโจทย์ที่คุณต้องการ: ___

3. สิ่งที่ชอบที่สุด 1 อย่าง: [ช่องว่าง]

4. สิ่งที่อยากให้ปรับปรุง 1 อย่าง: [ช่องว่าง]
```

### 💬 Prompt สำเร็จรูป

> 🏷️ **ใช้ใน:** `Claude Chat`

---

**Prompt 1 — เตรียมตอบ Q&A**

```
[Context] ฉันกำลังจะนำเสนอเรื่อง [หัวข้อ] ต่อ [Audience]
[Task] ช่วยเตรียม Q&A ที่น่าจะถูกถาม
[Spec]
สร้าง 5 คำถามที่น่าจะถูกถามมากที่สุด
พร้อมแนวทางตอบที่กระชับและน่าเชื่อถือ
[Constraint]
- คำถามต้องมาจากมุมมองของ [Audience]
- คำตอบไม่เกิน 3 ประโยค
- รวมคำถามยากที่ควรเตรียมรับมือ
```

---

**Prompt 2 — วิเคราะห์ Feedback ที่ได้รับ**

```
[Context] ฉันเพิ่งนำเสนอและได้ Feedback มาดังนี้:
[วาง Feedback ที่ได้รับ]
[Task] ช่วยวิเคราะห์ Feedback และสรุปสิ่งที่ต้องปรับปรุง
[Spec]
- จัดกลุ่ม Feedback เป็น: Content / Design / Delivery
- เรียง Priority จากสำคัญที่สุดไปน้อยที่สุด
- แนะนำวิธีแก้ไขที่เป็นรูปธรรมสำหรับแต่ละข้อ
[Constraint] เน้น Quick Wins ที่ทำได้ใน 1 ชั่วโมง
```

### 🛠️ Workshop — "Presentation Day"

> 🏷️ **Tool ที่ใช้:** Google Slides Presenter Mode ⏱️ **เวลาโดยประมาณ:** 3 ชั่วโมง

**โจทย์:** นำเสนอ Monthly Report Deck จากสัปดาห์ 8–9 ต่อผู้ฟังจริงอย่างน้อย 1 คน (ทีม/หัวหน้า/เพื่อน) เก็บ Feedback ครบ 3 คำถาม

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| นำเสนอต่อผู้ฟังจริงอย่างน้อย 1 คน | มี Witness | นำเสนอคนเดียว |
| เก็บ Feedback ครบ 3 คำถาม | มี Written Feedback | ไม่ได้ถาม |
| ผู้ฟังบอก Key Message กลับมาถูกต้อง | Key Message ถึง | ผู้ฟังจำผิด/จำไม่ได้ |
| นำเสนอได้ในเวลาที่กำหนด ±20% | ใกล้เคียง | เกินหรือขาดมาก |
