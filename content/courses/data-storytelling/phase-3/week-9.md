### 🔗 วิธี Share ใน Google Slides ที่ถูกต้อง

```
สถานการณ์ที่ 1: แชร์ให้ทีมแก้ไขร่วมกัน
→ Share → เพิ่ม Email → เลือก "Editor"
→ เหมาะกับ: ทีมที่ต้องทำงานร่วมกัน

สถานการณ์ที่ 2: ส่งให้หัวหน้าดูและ Comment
→ Share → เพิ่ม Email → เลือก "Commenter"
→ เหมาะกับ: ขอ Feedback โดยไม่ให้แก้เนื้อหา

สถานการณ์ที่ 3: แชร์ให้คนทั่วไปดูอย่างเดียว
→ Share → Change to anyone with the link → "Viewer"
→ เหมาะกับ: นำเสนอต่อคนที่ไม่มี Google Account

สถานการณ์ที่ 4: นำเสนอ Live ในการประชุม
→ Present → Full Screen
→ หรือ Share Screen ใน Zoom/Meet แล้ว Present
```

---

### 📤 Export สำหรับสถานการณ์ต่างๆ

```
Export เป็น PDF:
File → Download → PDF Document
→ ใช้เมื่อ: ส่งให้คนที่ไม่มี Google Account
→ ใช้เมื่อ: พิมพ์เอกสาร
→ ใช้เมื่อ: เก็บ Archive

Export เป็น PPTX:
File → Download → Microsoft PowerPoint
→ ใช้เมื่อ: คนรับต้องการแก้ไขด้วย PowerPoint
→ ⚠️ ตรวจ Font และ Layout หลัง Export เสมอ

Export เป็น PNG/JPG ทีละหน้า:
File → Download → PNG Image / JPEG Image
→ ใช้เมื่อ: นำสไลด์ไปใช้ใน Line/Email/Social Media

Publish to Web:
File → Share → Publish to web → Embed
→ ใช้เมื่อ: ต้องการ Embed สไลด์ในเว็บไซต์
→ สไลด์อัพเดตอัตโนมัติเมื่อแก้ไขต้นฉบับ
```

**Prompt — เตรียม Presentation Checklist ก่อนนำเสนอ**

```
[Context] ฉันต้องนำเสนอสไลด์นี้ [พรุ่งนี้/ในอีก X ชั่วโมง]
[Task] สร้าง Checklist สำหรับตรวจสอบก่อนนำเสนอ
[Spec]
ครอบคลุม:
- ตรวจ Content: Key Message, ตัวเลข, ข้อเท็จจริง
- ตรวจ Design: Font, สี, Alignment
- ตรวจ Technical: Link ใช้ได้, Chart แสดงผล, Animation
- ตรวจ Presenter: Speaker Notes, เวลา, Q&A ที่คาดว่าจะถาม
[Constraint] เป็น Checklist ที่ทำเสร็จได้ใน 15 นาที
```

**Acceptance Criteria ✅**

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| ผ่าน Presentation Checklist ครบ | ✅ ทุกข้อ | มีข้อที่ไม่ผ่าน |
| ซ้อมนำเสนอได้ภายในเวลาที่กำหนด | ไม่เกิน/ขาด 20% | เกินหรือขาดมาก |
| Share Link ให้คนอื่น Comment ได้ | คนอื่นเข้าถึงได้ | Link ไม่ทำงาน |
| Export PDF ได้ถูกต้อง | PDF หน้าตาตรงกับ Original | Font หรือ Layout ผิด |

### 🚨 Common Errors

| ปัญหาที่เจอ | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| Font หายใน PDF | ใช้ Font ที่ไม่ใช่ System Font | ใช้ Google Fonts ที่รองรับ PDF |
| Chart ไม่แสดงใน PPTX | Linked Chart ไม่ตาม | Unlink Chart ก่อน Export |
| คนรับ Link เปิดไม่ได้ | Share Settings เป็น Restricted | เปลี่ยนเป็น Anyone with link |
