## 📅 สัปดาห์ที่ 4 — สร้าง Prompt Library + Debug Prompt อย่างเป็นระบบ

### ⏱️ เวลาโดยประมาณ

ศึกษา 1 ชม. + Workshop 2 ชม.

---

### 😊 Jacky ขออธิบายเพิ่มเติมว่า

Prompt เหมือนสูตรอาหาร ครั้งแรกที่ทำอาจไม่อร่อย แต่ถ้าเรารู้ว่า "ขาดเกลือ" หรือ "เผ็ดเกิน" เราก็ปรับสูตรได้ ครั้งต่อไปก็ดีขึ้น

สัปดาห์นี้เรียนรู้ 2 สิ่ง:

1.  **Debug Prompt** — แก้ Prompt ที่ผลไม่ดีอย่างเป็นระบบ
2.  **สร้าง Prompt Library** — รวม Prompt ที่ดีที่สุดไว้ในที่เดียว

---

### ⚡ Quick Win (ลองทันที!)

เอา Prompt ที่เคยลองแล้วผลไม่ดีมา 1 อัน แล้วพิมพ์ใน ChatGPT ว่า:

```
Prompt ที่ฉันใช้คือ: [วาง Prompt เดิม]
ผลที่ได้คือ: [บอกสิ่งที่ไม่ชอบ]
สิ่งที่อยากได้จริงๆ คือ: [บอกสิ่งที่ต้องการ]
ช่วยปรับ Prompt ให้ดีขึ้นได้ไหม?
```

→ AI จะช่วย Debug Prompt ให้คุณเอง! ประหยัดเวลากว่านั่งงมเองมาก

---

### 📖 เนื้อหาหลัก: Debug Prompt อย่างเป็นระบบ

เมื่อผล Prompt ไม่ดี ให้วินิจฉัยตามตารางนี้:

| อาการ | วินิจฉัย | ยา (วิธีแก้) |
| --- | --- | --- |
| คำตอบยาวเกินไป | ไม่ได้จำกัดความยาว | เพิ่ม "ไม่เกิน \[จำนวน\] คำ/ข้อ/บรรทัด" |
| คำตอบสั้นเกินไป | ไม่ได้ขอรายละเอียด | เพิ่ม "อธิบายให้ละเอียด พร้อมตัวอย่าง" |
| ผิดภาษา | ไม่ได้ระบุภาษา | เพิ่ม "ตอบเป็นภาษาไทยเท่านั้น" |
| ไม่ตรงบริบทงาน | Context น้อยเกินไป | เพิ่มข้อมูลตำแหน่ง แผนก สายงาน |
| ทางการเกินไป | Spec ไม่ได้ระบุ Tone | เพิ่ม "โทนกันเอง ไม่ต้องเป็นทางการ" |
| ข้อมูลผิดพลาด | AI เดาข้อมูล | เพิ่ม "ใช้แค่ข้อมูลที่ฉันให้ อย่าเพิ่มเอง" |
| รูปแบบไม่ตรงใจ | Spec ไม่ได้ระบุ Format | ระบุ "ตอบเป็น bullet / ตาราง / ย่อหน้า" |
| ไม่ครบทุกประเด็น | Task ไม่ชัดพอ | แจกแจงสิ่งที่ต้องการทีละข้อ |

**กระบวนการ Debug 3 ขั้น:**

```
ขั้นที่ 1 — ระบุปัญหา
"ผลที่ได้ [บอกปัญหา] เพราะ Prompt ขาด [C/T/S/C ส่วนใด]"

ขั้นที่ 2 — แก้ส่วนที่ขาด
เพิ่ม/ปรับส่วนนั้นใน Prompt แล้วลองใหม่

ขั้นที่ 3 — ถ้ายังไม่ดี ถาม AI ตรงๆ
"ผลที่ได้ยังไม่ตรงที่ต้องการ
ปัญหาคือ: [ระบุ]
อยากให้ปรับเป็น: [ระบุ]
ช่วย rewrite Prompt ให้ใหม่ได้ไหม?"
```

### 💬 สร้าง Prompt Library ของตัวเอง

**Prompt Library คืออะไร?** ไฟล์ Note ส่วนตัวที่รวบรวม Prompt ที่ใช้ดีที่สุดของคุณไว้ในที่เดียว เพื่อ copy ไปใช้ได้ทุกเมื่อโดยไม่ต้องเขียนใหม่

**รูปแบบที่แนะนำ:**

```
## [ชื่อ Template]
- ใช้เมื่อ: [สถานการณ์ที่ใช้]
- เครื่องมือ: ChatGPT Free
- คะแนน: ⭐⭐⭐⭐⭐

[Context]    [ใส่ข้อมูล Context จริงของคุณ]
[Task]       [งานที่ต้องการ]
[Spec]       [รายละเอียด]
[Constraint] [ข้อจำกัด]

// หมายเหตุ: [สิ่งที่ต้องระวัง หรือเคล็ดลับ]
```

**ตัวอย่าง Prompt Library สำเร็จรูป:**

```
## 📧 ร่างอีเมลตอบลูกค้า
- ใช้เมื่อ: ต้องตอบ Email ลูกค้าภายใน 5 นาที
- คะแนน: ⭐⭐⭐⭐⭐

[Context]    ฉันทำงานฝ่าย [แผนก] บริษัท [ประเภทธุรกิจ]
[Task]       ช่วยร่างคำตอบ Email ลูกค้าต่อไปนี้
[Spec]       ภาษาไทย สุภาพ กระชับ ตอบครบทุกคำถาม ไม่เกิน 5 บรรทัด
[Constraint] อย่าสัญญาสิ่งที่ไม่แน่ใจ ถ้าไม่รู้ให้บอกว่าจะตรวจสอบแล้วแจ้งกลับ
---
[วาง Email ลูกค้า]

// หมายเหตุ: ถ้าเรื่องซับซ้อน เพิ่ม Background ของเรื่องใน Context

---

## 📋 สรุป Meeting Notes
- ใช้เมื่อ: หลังประชุม ต้องส่งสรุปให้ทีม
- คะแนน: ⭐⭐⭐⭐⭐

[Context]    ฉันเป็น [ตำแหน่ง] ต้องส่งสรุปให้ [ผู้รับ]
[Task]       ช่วยสรุป Meeting Notes ต่อไปนี้
[Spec]       3 หัวข้อ: ✅ ตัดสินใจแล้ว / 📋 Action Items / ❓ ค้างคา
             แต่ละหัวข้อไม่เกิน 5 ข้อ ภาษาไทย
[Constraint] ไม่เพิ่มข้อมูลที่ไม่มีใน Notes
---
[วาง Meeting Notes]

---

## 🌐 แปลเอกสารธุรกิจ
- ใช้เมื่อ: ได้รับเอกสารภาษาอังกฤษและต้องเข้าใจก่อนตัดสินใจ
- คะแนน: ⭐⭐⭐⭐

[Context]    ฉันต้องเข้าใจเอกสารก่อนเซ็น/ตอบกลับ
[Task]       แปลและสรุปเอกสารต่อไปนี้เป็นภาษาไทย
[Spec]       เน้นประเด็นสำคัญและสิ่งที่ต้องระวัง
             ไม่ต้องแปลคำต่อคำ เน้นความหมายที่ใช้งานได้
[Constraint] ถ้ามีศัพท์เทคนิค ให้อธิบายความหมายด้วย
---
[วางเอกสาร]
```

### 💼 ทำไมเรื่องนี้สำคัญในงาน

ทักษะที่แยก "คนใช้ AI เป็น" กับ "คนใช้ AI ไม่เป็น" ไม่ใช่การเขียน Prompt สวย — แต่คือ **การรู้ว่าต้องแก้อะไรเมื่อผลไม่ดี** คนที่ Debug Prompt เป็นและมี Library พร้อมใช้ ประหยัดเวลาได้ทุกวัน ส่วนคนที่ไม่มี ต้องนึกใหม่ทุกครั้งซึ่งทำให้ไม่อยากใช้ AI ในที่สุด

### 🛠️ Workshop — Final Deliverable

**โจทย์:** สร้าง Prompt Library ส่วนตัวที่ใช้งานได้จริง

**ขั้นตอน:**

1.  รวบรวม Prompt ที่ใช้ดีจาก Week 1-3 ทั้งหมด
2.  เพิ่ม Prompt ใหม่จนครบ 5 อัน ครอบคลุม ≥ 3 ประเภทงาน
3.  ทดสอบแต่ละ Prompt กับงานจริง ให้คะแนน ⭐ และจดหมายเหตุ
4.  เก็บไว้ใน Note (Notepad / Notion / Google Docs / ตามที่ถนัด)

| # | ประเภทงาน | ตัวอย่าง Template | สถานะ |
| --- | --- | --- | --- |
| 1 | งานเขียน/Email | ร่างอีเมล, แก้ข้อความ | ต้องมี |
| 2 | งานสรุป | สรุปประชุม, สรุปรายงาน | ต้องมี |
| 3 | งานแปล | แปลไทย-อังกฤษ | ต้องมี |
| 4 | งานวิเคราะห์ | เปรียบเทียบ, วิเคราะห์ข้อมูล | แนะนำ |
| 5 | งานเฉพาะของคุณ | เลือกเองตามสายงาน | แนะนำ |

### ✅ Acceptance Criteria Week 4 — Final

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| มี Prompt Library | มี ≥ 5 Prompt พร้อมใช้ใน Note | น้อยกว่า 5 อัน หรือไม่มีไฟล์ |
| ครอบคลุมหลายประเภทงาน | ≥ 3 ประเภทงานต่างกัน | ทั้งหมดงานประเภทเดียวกัน |
| ทดสอบจริงทุก Prompt | ทุก Prompt ผ่านการทดสอบกับงานจริง | มี Prompt ที่ยังไม่ได้ลอง |
| Debug Prompt ได้ | ปรับ Prompt ที่ผลไม่ดีได้โดยไม่ต้องถามใคร | ยังไม่รู้วิธีแก้เมื่อผลไม่ตรง |

### 🚨 Common Errors

| ปัญหา | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| รู้สึกว่า Library ยังไม่สมบูรณ์ ไม่อยากเก็บ | Perfectionism | เก็บได้เลยแม้ยังไม่สมบูรณ์ ค่อยปรับทีหลัง |
| ลืมว่าใช้ Prompt อะไร | ไม่ได้บันทึก | เปิด Note ทิ้งไว้ข้างๆ ทุกครั้งที่เปิด ChatGPT |
| AI ตอบดีบ้างไม่ดีบ้าง | Prompt ยังไม่นิ่ง | เพิ่ม Spec และ Constraint ให้ครอบคลุมมากขึ้น |
| ไม่รู้จะ Debug ตรงไหน | ไม่ได้วินิจฉัยปัญหาก่อน | ใช้ตาราง Debug 8 อาการข้างต้นตรวจสอบทีละข้อ |
