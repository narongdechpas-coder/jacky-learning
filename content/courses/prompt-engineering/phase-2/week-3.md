### 😊 Jacky ขออธิบายเพิ่มเติมว่า

ถ้าสัปดาห์ที่ 1-2 เราเรียนรู้ว่า "ทำอย่างไรให้สั่ง AI ได้ดี" สัปดาห์นี้เราจะ **"ยกงานจริงๆ มาลองกับ AI ตรงๆ"** เหมือนกับการฝึกขับรถในถนนจริง ไม่ใช่แค่ในลานจอดรถแล้ว

งานออฟฟิศส่วนใหญ่จัดอยู่ใน **4 กลุ่มหลัก** ที่ AI ช่วยได้เก่งมาก

> 🎯 **ไม่ต้องทำครบทุกกลุ่มในสัปดาห์นี้** — เลือก 2 กลุ่มที่ใช้บ่อยที่สุดในงานของคุณแล้วลงลึก ที่เหลือเก็บไว้เป็น Reference ใช้ตอนต้องการได้เลย

### 🎭 เทคนิคพิเศษ: Role Prompting — ให้ AI สวมบทบาท

ก่อนเข้าสู่ 4 กลุ่มงาน มีเทคนิคหนึ่งที่ทำให้ผลดีขึ้นทันที คือการบอก AI ให้ "เป็น" ผู้เชี่ยวชาญในสาขาที่คุณต้องการ

```
คุณคือ [บทบาท] ที่มีประสบการณ์ [X ปี] ด้าน [สาขา]
ช่วย [งานที่ต้องการ]
```

**ตัวอย่างที่ใช้งานได้จริง:**

```
คุณคือ Copywriter มืออาชีพที่เชี่ยวชาญการเขียนสำหรับแบรนด์ไทย
ช่วยเขียน Caption Instagram สำหรับสินค้า [ชื่อสินค้า]
โทนสดใส มีพลัง ความยาว 3 บรรทัด + hashtag 5 อัน
```

```
คุณคือนักกฎหมายที่ช่วยอธิบายสัญญาภาษาง่ายๆ
ช่วยอ่านสัญญาต่อไปนี้และบอกว่ามีประเด็นอะไรที่ควรระวังบ้าง
[วางสัญญา]
```

```
คุณคือผู้จัดการที่มีประสบการณ์ให้ Feedback พนักงาน
ช่วยปรับข้อความนี้ให้ฟังดู Constructive ไม่ดูวิจารณ์แบบ Negative
[วางข้อความ]
```

> 💡 ยิ่งบอกบทบาทชัด ยิ่งได้คำตอบที่ตรงกับมาตรฐานของสาขานั้น — ลองเปรียบเทียบกับการไม่ใส่บทบาทดูจะเห็นความต่างทันที

### ⚡ Quick Win (ลองได้เลยใน 3 นาที)

เปิด Email ล่าสุดที่ต้องตอบ → Copy มาวางใน ChatGPT → พิมพ์ต่อท้ายว่า:

```
ช่วยร่างคำตอบ Email นี้ให้หน่อย ภาษาไทย สุภาพ กระชับ ไม่เกิน 5 บรรทัด
```

→ ใช้เวลาไม่ถึง 3 นาที ได้ Draft อีเมลที่นำไปปรับใช้ได้เลย!

### 📖 เนื้อหาหลัก: 4 กลุ่มงานออฟฟิศที่ AI ช่วยได้

---

#### 📧 กลุ่มที่ 1 — งานเขียน (Email, รายงาน, บันทึก)

งานเขียนคือสิ่งที่ AI ช่วยได้ดีที่สุด เพราะเป็นงานที่ใช้ภาษาล้วนๆ

**สถานการณ์จริง:** คุณเป็นพนักงานขาย ต้องส่ง Follow-up Email หลังประชุมลูกค้า แต่ไม่รู้จะเขียนยังไงดี

```
[Context]    ฉันเป็นพนักงานขายบริษัทซอฟต์แวร์ เพิ่งประชุมกับลูกค้าใหม่ไปเมื่อวาน
[Task]       ช่วยเขียน Follow-up Email ให้ลูกค้า
[Spec]       - ขอบคุณที่สละเวลาประชุม
             - สรุปสิ่งที่คุยกัน 3 ประเด็นหลัก: [ระบุประเด็น]
             - แจ้ง Next Step ที่ตกลงกัน: [ระบุ]
             - ภาษาไทย สุภาพ เป็นมืออาชีพ
[Constraint] ไม่เกิน 10 บรรทัด ไม่ต้องพูดถึงราคา
```

**Template อื่นๆ ในกลุ่มนี้:**

```
# ขอเลื่อนนัด
ช่วยเขียนอีเมลขอเลื่อนนัดประชุมกับ [ผู้รับ] จาก [วันเดิม] เป็น [วันใหม่]
เหตุผล: [เหตุผล] ภาษาไทย สุภาพ กระชับ พร้อม Subject line

# ขอข้อมูล/เอกสาร
ช่วยเขียนอีเมลถึง [แผนก/บุคคล] ขอ [ข้อมูล/เอกสาร] ที่ต้องการ
เหตุผลที่ต้องการ: [เหตุผล] กำหนดส่ง: [วัน]

# แจ้งข่าวสารภายใน
ช่วยเขียนประกาศภายในบริษัทเรื่อง [หัวข้อ]
กลุ่มเป้าหมาย: [พนักงานทุกคน/แผนกที่เกี่ยวข้อง]
โทน: [ทางการ/กันเอง] ความยาว: [สั้น/ปานกลาง]
```

---

#### 📊 กลุ่มที่ 2 — งานสรุปและวิเคราะห์

AI เก่งมากในการดึงประเด็นสำคัญออกจากข้อมูลยาวๆ

**สถานการณ์จริง:** ประชุม 2 ชั่วโมง มี Meeting Notes ยาว 3 หน้า ต้องสรุปส่งทีม

```
[Context]    ฉันเป็น Project Manager ต้องส่งสรุปประชุมให้ทีม 10 คน ภายในวันนี้
[Task]       ช่วยสรุป Meeting Notes ต่อไปนี้
[Spec]       แบ่งเป็น 3 หัวข้อ:
             1. ✅ สิ่งที่ตัดสินใจแล้ว
             2. 📋 Action Items (ระบุผู้รับผิดชอบ + Deadline)
             3. ❓ ประเด็นที่ยังต้องหารือต่อ
             ภาษาไทย กระชับ แต่ละหัวข้อไม่เกิน 5 ข้อ
[Constraint] ไม่เพิ่มข้อมูลที่ไม่มีใน Notes ต้นฉบับ
---
[วาง Meeting Notes ตรงนี้]
```

**Template อื่นๆ ในกลุ่มนี้:**

```
# วิเคราะห์ข้อมูลตัวเลข
ฉันมีข้อมูล [ยอดขาย/ตัวเลข/รายงาน] ต่อไปนี้
ช่วยวิเคราะห์และบอกว่า:
1. Trend ที่น่าสังเกตคืออะไร?
2. จุดที่ดีที่สุดและแย่ที่สุดคืออะไร?
3. ข้อเสนอแนะ 2-3 ข้อ
ข้อมูล: [วางข้อมูล]

# เปรียบเทียบตัวเลือก
ฉันต้องเลือกระหว่าง [ตัวเลือก A] กับ [ตัวเลือก B]
ช่วยทำตารางเปรียบเทียบข้อดี-ข้อเสีย ในแง่มุม: [ราคา/ความสะดวก/คุณภาพ/อื่นๆ]
แล้วสรุปแนะนำตัวเลือกที่เหมาะกับ [เหตุผล/บริบท]
```

#### 🌐 กลุ่มที่ 3 — งานแปลและปรับภาษา

ไม่ว่าจะแปลไทย-อังกฤษ หรือปรับโทนเอกสาร AI ทำได้เก่งมาก

**สถานการณ์จริง:** ได้รับ Contract ภาษาอังกฤษ 2 หน้า ต้องเข้าใจก่อนเซ็น

```
[Context]    ฉันต้องตรวจสอบ Contract ก่อนเซ็น แต่ภาษาอังกฤษยาก
[Task]       ช่วยแปลและสรุป Contract ต่อไปนี้
[Spec]       - แปลเป็นภาษาไทยแบบเข้าใจง่าย
             - ไฮไลต์ประเด็นสำคัญที่ควรระวัง
             - บอกว่ามีข้อไหนที่ผิดปกติหรือควรถามทนายไหม
[Constraint] ไม่ต้องแปลคำต่อคำ เน้นความหมายที่ใช้งานได้จริง
---
[วาง Contract ตรงนี้]
```

**Template อื่นๆ ในกลุ่มนี้:**

```
# แปลอีเมลธุรกิจ
แปลอีเมลต่อไปนี้เป็นภาษาไทย แบบทางการ รักษาความหมายเดิมทุกคำ
[วางอีเมลภาษาอังกฤษ]

# ปรับภาษาให้เป็นทางการมากขึ้น
ข้อความนี้ฉันเขียนแบบกันเอง ช่วยปรับให้เป็นทางการ
เหมาะกับ: [อีเมลหาลูกค้า/รายงานผู้บริหาร/หนังสือราชการ]
[วางข้อความต้นฉบับ]

# ตรวจ Grammar ภาษาอังกฤษ
ช่วยตรวจ Grammar และ Spelling ของข้อความนี้
แล้วอธิบายว่าแก้ตรงไหนบ้างและทำไม
[วางข้อความภาษาอังกฤษ]
```

#### 💡 กลุ่มที่ 4 — งานสร้างไอเดียและวางแผน

AI ช่วย Brainstorm ได้เร็วกว่ามากเมื่อเทียบกับนั่งคิดคนเดียว

**สถานการณ์จริง:** ต้องเสนอแผนจัดงาน Team Building บริษัทภายใน 2 วัน

```
[Context]    ฉันเป็น HR ต้องจัด Team Building สำหรับพนักงาน 50 คน งบ 30,000 บาท
[Task]       ช่วยเสนอแผน Team Building 3 รูปแบบ
[Spec]       แต่ละรูปแบบระบุ:
             - ชื่อกิจกรรม + คอนเซ็ปต์
             - สถานที่แนะนำ
             - ขั้นตอนหลัก 3-4 ข้อ
             - งบประมาณโดยประมาณ
[Constraint] ทำในกรุงเทพหรือปริมณฑล ระยะเวลาครึ่งวัน ไม่ใช้กิจกรรมที่ต้องออกแรงมาก
```

**Template อื่นๆ ในกลุ่มนี้:**

```
# ขอไอเดีย Content
ฉันดูแล Social Media ให้ [ประเภทธุรกิจ]
ช่วยเสนอไอเดีย Content สำหรับ [เดือน/งาน/ธีม] 10 ไอเดีย
แต่ละไอเดียบอก: หัวข้อ + โทน + Platform ที่เหมาะ

# วางแผนโปรเจกต์
ฉันต้องทำโปรเจกต์ [ชื่อโปรเจกต์] ให้เสร็จภายใน [ระยะเวลา]
ช่วยร่างแผนงานออกเป็น Milestone หลักๆ พร้อม Task ย่อย
ทรัพยากรที่มี: [คน/งบ/เวลา]
```

### 💼 ทำไมเรื่องนี้สำคัญในงาน

คนที่ใช้ AI ได้ผลดีในออฟฟิศไม่ได้แค่ "ถามเก่ง" — แต่รู้ว่างานประเภทไหน AI ช่วยได้มากและน้อยแค่ไหน สัปดาห์นี้คือจุดเปลี่ยนที่คุณจะเริ่มเห็นว่า AI ช่วยงานจริงๆ ของคุณได้ไหม และต้องปรับ Template ยังไงให้ตรงกับสายงานของตัวเอง

### 🛠️ Workshop

**โจทย์:** ลองใช้ Prompt กับงานจริง อย่างน้อย 2 กลุ่มงาน

**ขั้นตอน:**

1.  เลือก 2 กลุ่มงานที่คุณเจอบ่อยที่สุดจาก 4 กลุ่มข้างต้น
2.  ลองใช้ Template ที่ให้ไว้กับงานจริงของคุณ
3.  ปรับ Template ให้ตรงกับสายงานของคุณ
4.  บันทึก Template ที่ใช้ได้ผลดีไว้ใน Note

**เคล็ดลับ:** อย่าลองแค่ Template ตัวอย่าง ลองเปลี่ยนเป็นงานจริงของคุณเลยดีกว่า เพราะจะเห็นว่าต้องปรับอะไรบ้างถึงจะใช้ได้

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| ลองครบ ≥ 2 กลุ่มงาน | มีผลลัพธ์จากงานจริงอย่างน้อย 2 ชิ้น | ลองแค่กลุ่มเดียว |
| ปรับ Template ให้ตรงงานตัวเอง | Template มีชื่อตำแหน่ง/บริษัท/บริบทจริง | ใช้ Template ตัวอย่างโดยไม่ปรับ |
| บันทึก Template ที่ดี | มี Template เก็บไว้ใช้ซ้ำ ≥ 2 อัน | ทำแล้วไม่ได้เก็บ |
| AI ช่วยงานจริงได้สำเร็จ | มีงานอย่างน้อย 1 ชิ้นที่ AI ช่วยได้จริง | ผลออกมาไม่ตรงใจทุกครั้ง |

### 🚨 Common Errors

| ปัญหา | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| AI ตอบถูกแต่ใช้งานไม่ได้จริง | Template ไม่ได้ปรับให้ตรงบริบทจริง | เพิ่มรายละเอียดเฉพาะของงานตัวเอง เช่น ชื่อลูกค้า ตัวเลขจริง |
| ผลดีบางครั้ง ไม่ดีบางครั้ง | Prompt ไม่ consistent | กำหนด Spec ให้ชัดขึ้น โดยเฉพาะ Format และ Tone |
| ไม่แน่ใจว่า AI ถูกหรือเปล่า | AI อาจ "เดา" ข้อมูลที่ไม่มี | เพิ่ม "ใช้เฉพาะข้อมูลที่ฉันให้ ถ้าไม่รู้ให้บอกว่าไม่รู้" |
