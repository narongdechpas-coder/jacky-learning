### 😊 Jacky ขออธิบายเพิ่มเติมว่า

เวลาเราสั่งอาหารร้านใหม่ที่ไม่รู้จัก ถ้าบอกแค่ว่า *"เอาอาหาร"* พ่อครัวก็ทำอะไรก็ได้ แต่ถ้าบอกว่า *"เอาข้าวผัดกุ้ง ไม่เผ็ด ใส่ไข่ดาว ไม่ใส่ผัก ปริมาณปกติ"* พ่อครัวก็รู้ทันทีว่าต้องทำอะไร

Prompt ก็เหมือนกัน เราใช้ **C-T-S-C Framework** เพื่อบอก AI ให้ครบทุกด้านในทีเดียว

```
[C] Context    = ฉันเป็นใคร บริบทของงานคืออะไร
[T] Task       = ต้องการให้ทำอะไรกันแน่
[S] Spec       = รูปแบบ ภาษา ความยาว สไตล์
[C] Constraint = ข้อจำกัด สิ่งที่ไม่ต้องการ
```

ไม่จำเป็นต้องครบทุกส่วนในทุก Prompt แต่ยิ่งครบ ยิ่งได้ผลดี

---

### ⚡ Quick Win (ลองทันที!)

Copy Prompt ด้านล่าง แก้ส่วน `[วงเล็บ]` แล้วลองใช้ใน ChatGPT เลย:

```
[Context]    ฉันทำงานเป็น [ตำแหน่งของคุณ] ที่บริษัท [ประเภทธุรกิจ]
[Task]       ช่วยเขียนอีเมลถึง [ผู้รับ] เรื่อง [หัวข้อ]
[Spec]       ภาษาไทย สุภาพ กระชับ ไม่เกิน 5 บรรทัด มี Subject line ด้วย
[Constraint] ไม่ต้องมีคำทักทายยาว เริ่มเนื้อหาได้เลย
```

→ ลองเปรียบเทียบกับครั้งก่อนที่ไม่ได้ใช้ Framework เห็นความต่างไหม?

### 📖 เนื้อหาหลัก: C-T-S-C ในสถานการณ์จริง

#### สถานการณ์ที่ 1: พนักงานบัญชีต้องส่งรายงานให้ผู้จัดการ

**Prompt ก่อนเรียน (ไม่มี Framework):**

```
ช่วยเขียนรายงานสรุปยอดขาย
```

**Prompt หลังเรียน (ใช้ C-T-S-C):**

```
[Context]    ฉันทำงานบัญชีบริษัทนำเข้าสินค้า ต้องส่งรายงานให้ผู้จัดการทุกเดือน
[Task]       ช่วยเขียนสรุปยอดขายประจำเดือนมิถุนายน
[Spec]       รูปแบบ: ตารางเปรียบเทียบเดือนนี้ vs เดือนก่อน + วิเคราะห์สั้นๆ 3 ประเด็น
             ภาษาไทย ทางการ
[Constraint] ไม่ต้องมีกราฟ ใช้แค่ตัวเลขและข้อความ
             ข้อมูล: [วางตัวเลขยอดขาย]
```

#### สถานการณ์ที่ 2: ฝ่ายการตลาดต้องเขียน Post โซเชียล

```
[Context]    ฉันทำงาน Social Media ให้แบรนด์เครื่องสำอางไทย
[Task]       ช่วยเขียน Caption สำหรับ Instagram
[Spec]       เรื่อง: ลิปสติกสีใหม่คอลเลกชันหน้าร้อน
             โทน: สดใส มีพลัง ใช้ emoji พอประมาณ
             ความยาว: 3-4 บรรทัด + hashtag 5 อัน
[Constraint] ไม่ใช้คำว่า "ราคาพิเศษ" หรือ "โปรโมชัน"
```

#### สถานการณ์ที่ 3: HR ต้องตอบคำถามพนักงาน

```
[Context]    ฉันเป็น HR บริษัทเทคโนโลยี พนักงาน 150 คน
[Task]       ช่วยร่างคำตอบ Email ให้พนักงานที่ถามเรื่องสวัสดิการประกันสุขภาพ
[Spec]       ภาษาไทย สุภาพ เป็นมิตร ชัดเจน ตอบครบคำถามที่ถาม
[Constraint] อย่าให้ข้อมูลที่ยังไม่แน่ใจ ถ้าไม่รู้ให้บอกว่าจะตรวจสอบแล้วแจ้งกลับ
             Email ที่พนักงานส่งมา: [วาง Email พนักงาน]
```

### 💬 Prompt สำเร็จรูป

#### Template: สรุปเอกสารยาวๆ

```
[Context]    ฉันต้องนำเสนอสรุปให้หัวหน้าฟังในที่ประชุมพรุ่งนี้
[Task]       ช่วยสรุปเอกสารต่อไปนี้
[Spec]       รูปแบบ bullet point 5 ข้อหลัก แต่ละข้อไม่เกิน 2 บรรทัด
             ภาษาไทย กระชับ เข้าใจง่าย
[Constraint] เน้นประเด็นที่ส่งผลต่อการตัดสินใจ ไม่ต้องใส่รายละเอียดย่อย
---
[วางเอกสารที่ต้องการสรุปตรงนี้]
```

#### Template: ปรับโทนการเขียน

```
[Context]    ฉันเขียนข้อความนี้แล้วแต่รู้สึกว่ายังไม่ดีพอ
[Task]       ช่วยปรับโทนการเขียนให้ดูดีขึ้น
[Spec]       โทนที่ต้องการ: [สุภาพ/กันเอง/ทางการ/มีพลัง]
             คงเนื้อหาเดิมไว้ แค่ปรับภาษา
[Constraint] ไม่เปลี่ยนความหมาย ไม่เพิ่มข้อมูลใหม่
---
[วางข้อความที่ต้องการปรับ]
```

### 🔄 เทคนิคเสริม: สนทนาต่อเนื่อง (ไม่ต้องเริ่มใหม่ทุกครั้ง)

AI จำบทสนทนาทั้งหมด **ภายในหน้าต่างเดิม** ได้ — ดังนั้นถ้าผลยังไม่ดีพอ ไม่ต้องเปิดแชทใหม่หรือเขียน Prompt ใหม่ทั้งหมด สั่งต่อในแชทเดิมได้เลย:

```
ดี แต่ขอให้สั้นลงอีกครึ่งหนึ่ง และเปลี่ยนโทนให้เป็นทางการขึ้น
```

```
เวอร์ชันนี้ดีกว่า แต่เปลี่ยนย่อหน้าที่ 2 ใหม่ทั้งหมด เน้นประโยชน์ที่ลูกค้าได้รับ
```

```
เพิ่มตัวอย่างจริงๆ 1 ข้อในแต่ละประเด็น
```

**⚠️ จำไว้:** ถ้าเปิดแชทใหม่ AI จะลืมทุกอย่าง ต้องบอก Context ใหม่ตั้งแต่ต้น ดังนั้นถ้างานยังไม่เสร็จ อย่าปิดแชท

### 💼 ทำไมเรื่องนี้สำคัญในงาน

คนส่วนใหญ่ใช้ AI แบบ "ลองแล้วไม่ได้ผล → เลิกใช้" เพราะไม่มี Framework ทำให้ทุกครั้งที่เริ่มใหม่ต้องนึกใหม่ตั้งแต่ต้น C-T-S-C คือ "สูตร" ที่ทำให้คุณเขียน Prompt ดีได้แม้ในสถานการณ์ที่ไม่เคยเจอมาก่อน — และเมื่อผลไม่ดี ก็รู้ทันทีว่าต้องแก้ส่วนไหน

### 🛠️ Workshop

**โจทย์:** เขียน Prompt C-T-S-C สำหรับงานจริงของคุณ 2 ชิ้น

**ขั้นตอน:**

1.  เลือกงาน 2 อย่างที่ทำบ่อยที่สุดในสัปดาห์นี้
2.  เขียน Prompt โดยใส่ครบทั้ง C, T, S, C
3.  ทดสอบกับ ChatGPT แล้วดูว่าผลตรงใจไหม
4.  ถ้ายังไม่ดีพอ ลองปรับแค่ Spec หรือ Constraint แล้วลองใหม่

**เคล็ดลับ:** ถ้าผลยังไม่ดี ลองถาม ChatGPT ต่อว่า:

```
ผลที่ได้ยังไม่ตรงที่ต้องการเพราะ [บอกปัญหา]
ช่วยปรับให้ [บอกสิ่งที่อยากได้] ได้ไหม?
```

### ✅ Acceptance Criteria

| เกณฑ์ | ผ่าน ✅ | ไม่ผ่าน ❌ |
| --- | --- | --- |
| เข้าใจ C-T-S-C | อธิบายแต่ละส่วนให้คนอื่นฟังได้ | จำได้แต่ไม่รู้ว่าแต่ละส่วนคืออะไร |
| เขียน Prompt ด้วย C-T-S-C | เขียนได้ครบ 4 ส่วน | มีแค่ 1-2 ส่วน |
| ทดสอบกับงานจริง ≥ 2 ชิ้น | ChatGPT ช่วยงานจริงได้ผล | ลองแค่ตัวอย่างสมมติ |
| บันทึก Prompt ที่ดี | มี Prompt เก็บไว้ใช้ซ้ำ ≥ 1 อัน | ลองแล้วไม่ได้เก็บ |

### 🚨 Common Errors

| ปัญหา | สาเหตุ | วิธีแก้ |
| --- | --- | --- |
| ผลออกมาทางการเกินไป | Spec ไม่ได้ระบุ Tone | เพิ่มใน Spec เช่น "ภาษากันเอง ไม่ต้องเป็นทางการ" |
| AI เพิ่มข้อมูลที่ไม่ต้องการเข้ามา | Constraint ไม่ชัด | เพิ่ม "ใช้แค่ข้อมูลที่ฉันให้ อย่าเพิ่มเอง" |
| ผลยังไม่ดีแม้ครบ C-T-S-C | Spec ยังกว้างเกินไป | ลองระบุให้เฉพาะเจาะจงขึ้น เช่น แทน "กระชับ" เป็น "ไม่เกิน 3 ประโยค" |
| ไม่รู้จะใส่อะไรใน Context | ไม่แน่ใจว่าข้อมูลไหนสำคัญ | ถามตัวเองว่า "ถ้าจ้างคนใหม่ทำงานนี้ ต้องบอกเขาว่าอะไรบ้าง?" |
